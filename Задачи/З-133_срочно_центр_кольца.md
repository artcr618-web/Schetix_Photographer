# З-133 · СРОЧНО: сломанный центр кольца после восстановления по исходнику
Приоритет: P1

## Слово владельца

«У тебя серьезная ошибка в кольце срочно исправь!!!»

## Что сломалось

При З-132 (возврат donut() по исходнику GitHub) вместе с диаграммой
вернулась и ИСХОДНАЯ svg-иконка «₽» в центре (.mi). Но CSS для .mi
давно другой (принятый владельцем З-125: текстовая плашка «1 час»
с font-size, без width/height). Иконка без ограничений размера
растянулась на всё кольцо (255×255px) и перекрыла центр — цифры
«9 430 ₽» и подпись были не видны.

Подтверждено скриншотом Chromium до правки:
Инструменты/диагностика/кольцо_с_ошибкой.png.

## Исправление

В хвосте donut() возвращён принятый владельцем центр для большого
кольца: «1 час / 9 430 ₽ / за час съёмки» (как в З-125). Малым
кольцам — исходная иконка (их CSS не менялся). САМА диаграмма,
восстановленная по исходнику (сектора, маски, порядок, цвета,
градиенты), не тронута.

## Проверка (Chromium, реальный рендер)

- центр: «1 час / 9 430 ₽ / за час съёмки»; .mi — текст «1 час»,
  35×19px (плашка), иконки в центре НЕТ.
- 12 секторов, 12 исходных масок — диаграмма по исходнику на месте.
- края кольца целые: внутренний и внешний радиусы — 0 светлых
  пикселей (разрывов нет); на средней линии светлые пиксели —
  только белые цифры-проценты.
- собрать.py: ✓ (612 КБ, prev43). проверить.py: 121 · 0 · 1.
  Скриншот: Инструменты/диагностика/кольцо_з133.png.
