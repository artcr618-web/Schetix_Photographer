## Зачем

Рабочая версия отчёта содержит встроенный технический DEMO-набор: при прямом открытии без данных анкеты он показывает расчёт по умолчанию. Для публикации нужна вторая копия калькулятора без DEMO-режима, чтобы посетитель никогда не видел примерные значения вместо собственного расчёта.

## Что сделать

- [ ] Сохранить текущую рабочую копию с DEMO для разработки и автоматических проверок
- [ ] Перед выгрузкой определить отдельный путь и имя публикационной копии
- [ ] Создать вторую копию калькулятора для публикации
- [ ] Удалить из публикационной копии встроенный DEMO-набор и обращение к нему
- [ ] При отсутствии данных анкеты показывать пустое состояние с предложением заполнить анкету, а не расчёт по умолчанию
- [ ] Проверить передачу реальных данных из анкеты в публикационный отчёт
- [ ] Проверить, что в публикационных файлах не осталось DEMO-значений
- [ ] Прогнать автоматические и браузерные проверки публикационной копии
- [ ] Выгружать на сайт только копию без DEMO-режима

## Решения и правки

- 22.08.2026 — задача заведена.
- 22.08.2026 — Решение пользователя: перед выгрузкой оставить рабочую техническую версию и создать вторую копию калькулятора, в которую DEMO-режим не включён.
