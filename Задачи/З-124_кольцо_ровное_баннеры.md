## Зачем

Слово владельца (27.08): «По цвету баннеров: зелёный оставляем, голубой
в целом тоже, красный — как будто оранжевый: возьмём оттенки с кольца
диаграммы и сделай баннер таким. Убрать подчёркивание на баннере —
стилистический элемент, мы не используем его в других деталях
оформления документа. Между линейной диаграммой и следующим баннером
оставлять больше места — сейчас слипшиеся. Кольцо имеет неровный край:
деформируется по внешнему кольцу внутрь и по внутреннему ещё раз внутрь,
как выемка — её нужно убрать.»

## Что сделать

- [x] Кольцо: у секторов убрать диагональный градиент (светлый →
      базовый → тёмный по bbox сектора) — тёмный стоп затемнял внешнюю
      и внутреннюю дуги, читалось как «выемка»/наложение другой формы.
      Сектора — плоская заливка чистым цветом: край ровный, кольцо
      цельное (как полосы линейных диаграмм).
- [x] Баннер расходов: убрать оранжевый конец; гамма — красные
      секторы кольца: #C43D51 → #D6563A → rgba(214,86,58,.6).
- [x] Баннеры дохода и резерва — без изменений (слово владельца:
      зелёный нормальный, голубой в целом тоже).
- [x] Убрать цветную полосу-«подчёркивание» по нижнему краю баннеров
      (::after из З-116) — чужой стилистический элемент.
- [x] Отступ диаграмма → баннер: .exp/.res 38px → 52px, базовый
      .dnsum −6px → 28px — баннеры визуально отделяются.
