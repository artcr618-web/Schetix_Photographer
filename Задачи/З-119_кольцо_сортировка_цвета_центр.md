## Зачем

Слово владельца (27.08): раздел «Доходы» кольца — выстроить от большего
сектора к меньшему; это касается и заливки — по принципу линейной
диаграммы, насыщенность прежняя, зелёный — из главного баннера.
Резервы и форс-мажоры оформить в стиле диаграммы: голубой — из линейной
диаграммы, серый форс-мажор — с насыщенностью 7%, а не 100. В расходах —
разместить сектора от большего к меньшему, цветность оставить. Иконку
рубля из центра убрать (символ задваивался): «1 час» — крупно, под
подчёркиванием — «на съёмке».

## Что сделать

- [x] Доходы: секторы отсортированы по убыванию; заливка — по рангу,
      как строки линейной диаграммы: больший сектор насыщеннее.
      Гамма — главного баннера: g-800 #0B6B22 → g-500 #21A038.
      Объёмный градиент сектора (светлый верх / тон / тёмный низ)
      сохранён — «насыщенность оставляем как сейчас».
- [x] Резервы: голубые из линейной диаграммы CO[11..13]
      (#3B82F6/#5CA8E0/#8FC7E8), единое правило — по рангу от большего
      к меньшему (в дефолте отпуск — единственный — стал тёмно-голубым
      #3B82F6 вместо светлейшего #8FC7E8).
- [x] Форс-мажоры и простой: серый #C5D0C8 из линейной диаграммы,
      заливка плоская с насыщенностью 7% (fill-opacity 0.07, было 100%);
      без градиента, как полосы легенды.
- [x] Расходы: секторы по убыванию, цветность прежняя (CO[6..10]
      по рангу).
- [x] Надписи процентов на секторах — в стиле сектора: на голубих —
      тёмно-синий #1D4ED8 (b-800), на сером — тёмно-серый #374151
      (было тёмно-зелёное #14532D «не в стиле»).
- [x] Центр: иконка рубля убрана; «1 час» — крупно (прежний кегль
      цифры, clamp + container-query); под подчёркиванием (линия .k
      сохранена) — «на съёмке». Число ставки из центра ушло (₽ больше
      не дублируется), подпись «за час съёмки» в малых кольцах
      сценариев не тронута.
- [x] Легенды под кольцом — прежнего порядка (З-114/З-115):
      сортировка сделана только для кольца (VIS в месте вызова),
      visIdx вернул безусловные резервы 11/12/13 — от них зависят
      zero-строки «не заложен» с кнопками.

## Решения и правки

- 27.08.2026 — внесено з119_кольцо.py + доделка з119б_кольцо.py:
  первая версия сортировала сам visIdx — легенды под кольцом
  переставились, а выключенные резервы (P=0) выпали из списка —
  исчезли zero-строки «не заложен» и кнопки. Поймано jsdom-прогоном
  (zero ×0), ассерты до записи не задели этот случай. Исправлено:
  сортировка только в VIS у вызова donut.
- «1 час» / «на съёмке» — из двух предложенных владельцем подписей
  («на съёмке» / «на съёмочной площадке») взята короткая: центр узкий.
