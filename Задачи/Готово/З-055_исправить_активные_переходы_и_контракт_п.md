## Зачем

Действующие переходы не должны вести на отсутствующие локальные страницы или якоря. Показатель «Прямые расходы на готовый кадр» — финансовый результат анкеты: отчёт не должен самостоятельно собирать его fallback-формулой из деталей, иначе появляются два источника истины.

## Что сделать

- [x] Исправить активную ссылку прайса на существующий якорь детализации отчёта.
- [x] Исправить только устаревший якорь детализации; предназначение `preview.html` уточняется владельцем отдельной задачей З-056.
- [x] Рассчитать `directFrameCosts` в `calc()`, передать его в `d` и описать обязательным полем контракта.
- [x] Убрать финансовый fallback из development- и производного публикационного отчётов, сохранив тот же состав суммы и баланс модели.
- [x] Привести B008 к согласованным состояниям: автоматический заголовок, обычный вопрос ручного выбора, обменённые визуальные роли кнопок при сохранении текста и пиктограмм.
- [x] Обновить DEMO, golden snapshot, документацию и постоянные browser/source/contract проверки.
