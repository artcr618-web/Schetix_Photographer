## Зачем

Рабочий `report.html` содержит встроенный технический DEMO-набор: при прямом открытии без данных анкеты он показывает чистый старт разработки. Для публикации нужен отдельный производный отчёт без DEMO, чтобы посетитель никогда не видел примерные значения вместо собственного расчёта. Это не самостоятельная страница: без переданного результата она ведёт в анкету.

- [x] Создать публикационный отчёт как производный артефакт, а не вторую редактируемую ветку калькулятора
