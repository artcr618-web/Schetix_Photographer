## Зачем

Общий старый `проверить.py` смешивал исполняемую цепочку `index → calc → report / price`
с книгой, архивом, PDF, каркасом и историческими ожиданиями. Из-за этого рабочий
веб-контур не мог иметь понятного зелёного статуса: после принятых browser/default
исправлений общий прогон всё ещё завершался историческими падениями.

Задача создаёт честный обязательный гейт только для активных страниц. Исторический
аудит сохраняется доступным отдельно, но не блокирует веб-контур. Книга,
`Веб/Части/каркас.html`, архив и PDF не меняются.

- [x] Включить в неё компиляцию четырёх активных страниц, browser-default, DEMO report/price, пустой харнесс, финансовые инварианты, сценарий сотрудников и headless-report.
- [x] Сделать обычный `проверить.py [корень]` запуском активного гейта с кодом 0 при зелёном веб-контуре.
