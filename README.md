# Счётикс — калькулятор стоимости часа для фотографов

Счётикс рассчитывает юнит-экономику съёмочного часа: какую ставку установить,
чтобы покрыть Финансовые расходы, Налоги, Страховые взносы, банковские
комиссии и предусмотренные резервы и получить Желаемый доход.

Расчёт выполняется в браузере: `Веб/calc.html`, функция `calc()`. Бэкенд для
расчёта не требуется.

## Что нельзя

- Использовать архивные книги и документы как текущий источник.
- Создавать вторую формулу в report, если показатель должен приходить из
  `calc()`.
- Менять понятие, определение, состав или пользовательское название без решения
  владельца.
- Править только `report.html`: его каркас должен изменяться одновременно.
- Перезаписывать основную книгу вручную без последующего пересчёта и проверки.
- Добавлять формулы Microsoft 365: книга поддерживает старые версии Excel и
  LibreOffice через обычные совместимые формулы.
- Публиковать техническую версию с DEMO; перед публикацией выполняется З-039.
