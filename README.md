# СЧЁТИКС — калькулятор стоимости часа для фотографов

Юнит-экономика одного часа съёмки: анкета → отчёт, сколько должен стоить час,
чтобы после расходов, налогов и комиссий остался желаемый доход. Всё считается
в браузере (`Веб/calc.html`, функция `calc()`), бэкенда нет.

## С чего начать — по цели

| Цель | Открыть |
|---|---|
| продолжить работу | `Документация/ДОРОЖНАЯ_КАРТА.md` — этап, живой список изменений, открытые решения, правила. **Первый файл в каждом разговоре** |
| понять, как всё устроено | `Документация/03_ПОЛНАЯ_МЕХАНИКА_И_АЛГОРИТМЫ_25авг_2026.md` — вся механика, все листы книги, карта влияния правок |
| что-то поправить | `Документация/АЛГОРИТМЫ.md` — рецепты по шагам |
| проработать расчёт | `Документация/Описания расчётов/00_РЕЕСТР_РАСЧЁТОВ.md` — 47 расчётов, по одному проговариваем и фиксируем паспортом |
| готовить запуск | `Документация/Подготовка к запуску/` — домен, платежи, публикация, стратегия |
| как работать с ассистентом | `Документация/00_АЛГОРИТМ_ВЗАИМОДЕЙСТВИЯ_И_ТЕКУЩАЯ_СТАДИЯ.md` — регламент |

## Корень

| Папка | Одной строкой |
|---|---|
| `Веб/` | сам продукт: три страницы, их части, счётчики |
| `Книга/` | `Калькулятор_ставки_часа.xlsx` — 31 лист: параметры, каталоги, расчёт, глоссарий, реестры |
| `Инструменты/` | все рабочие скрипты: проверки, генераторы, сборка, задачи |
| `Задачи/` | по документу на задачу + авто-реестр; закрытые — в `Архив/Задачи/` |
| `Документация/` | вся документация (состав — по целям выше) |
| `Архив/` | история, окно 5 дней; изображения — только ручное удаление |

Три источника правды: расчёт — `calc()`; названия — словарь `СПРАВОЧНИК`
в `Инструменты/таблицы_прототип.py`; понятия — лист `01_Глоссарий` книги.
Подробная карта каждого файла — в томе 03, здесь не дублируется.

## Рабочий цикл правки

```bash
# 1. свериться с планом и живым списком: Документация/ДОРОЖНАЯ_КАРТА.md
# 2. править ИСТОЧНИК (calc(), словарь, лист книги) — не представление
# 3. пересобрать представления генераторами из Инструменты/
# 4. проверка — «упало» должно быть 0:
python3 Инструменты/проверить.py /home/user/schetix
```

Мелкое «не забыть» — строка в живой список карты; крупная работа — задача:
`python3 Инструменты/задачи.py новая "Название" P0`.

## Перенос в новую сессию

Рабочая среда не переживает перезапуск — восстановление по шагам:

```bash
# 1. забрать проект и сделать симлинк (скрипты ждут /home/user/schetix)
git clone https://github.com/artcr618-web/Schetix_Photographer /home/user/Schetix_Photographer
ln -s /home/user/Schetix_Photographer /home/user/schetix

# 2. поставить пакеты, которых нет в чистой среде
pip install formulas openpyxl        # formulas — для пересчёта книги
cd /tmp && npm install jsdom         # для проверок отчёта без браузера

# 3. убедиться, что всё на месте: должно быть 115 прошло · 0 упало
python3 Инструменты/проверить.py /home/user/schetix

# 4. задачи и план
python3 Инструменты/задачи.py список
#    и прочитать Документация/ДОРОЖНАЯ_КАРТА.md + 00_АЛГОРИТМ_ВЗАИМОДЕЙСТВИЯ

# 5. сервер для просмотра
python3 -m http.server 3002 --bind 0.0.0.0 --directory /home/user/schetix/Веб
```

Не переживают перезапуск: установленные пакеты, запущенный сервер,
состояние браузера. Сам проект целиком живёт в git — ничего не теряется.

## Что нельзя

- Опираться на `Архив/` — там история, не рабочие файлы.
- Править представления руками (DEMO, справочник в отчёте) — только генераторами.
- Заводить одни данные в двух местах.
- Писать книгу в обход zip-инструментов (openpyxl целиком теряет диаграммы).
- Переименовывать и менять состав таблиц без явного «да» владельца.
