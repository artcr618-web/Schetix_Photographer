РАБОЧИЕ ФАЙЛЫ — их всего три
═══════════════════════════════════════════════════════════

Калькулятор_ставки_часа.xlsx    книга: логика, параметры, тексты, методика
web/calc.html                    форма-анкета для Tilda
web/report.html                  полный отчёт после оплаты
                                 СОБИРАЕТСЯ, руками не править:
                                 правки идут в web/части/каркас.html,
                                 потом python3 собрать.py

Оба HTML автономны: картинки и стили вшиты внутрь,
никаких дополнительных файлов для работы не нужно.

web/собрать.py    склейка отчёта + проверки. После любой правки:
                  cd web && python3 собрать.py
web/блок.py       вынести блок из отчёта, чтобы править отдельно:
                  python3 блок.py список
                  python3 блок.py вынести 03
                  python3 блок.py вернуть 03

═══════════════════════════════════════════════════════════
КАК ПРАВИТЬ БЛОК ОТДЕЛЬНО
═══════════════════════════════════════════════════════════

Править блок прямо в каркасе тяжело: файл на 300 КБ, соседние
блоки мешают, вёрстка съезжает незаметно. Поэтому блок можно
вынести, спокойно доработать и вернуть обратно.

  1. python3 блок.py вынести 03
     Блок уезжает в части/03.html — это ПОЛНОЦЕННАЯ страница
     со всеми стилями и настоящими цифрами, её видно как есть.

     Блок называется по НОМЕРУ, который виден в отчёте: 01, 02, 03…
     В вёрстке у блоков исторические id (у блока 03 это card06) —
     менять их нельзя, на них завязан CSS. Файлы и команды идут
     по номеру, чтобы не путаться.

  2. Правите файл ТОЛЬКО между метками:
       <!--БЛОК-НАЧАЛО-->  ... сам блок ...  <!--БЛОК-КОНЕЦ-->
     Всё вокруг — обвязка для просмотра, в отчёт она не идёт.

  3. python3 собрать.py
     Отчёт уже собирается с вашими правками — можно проверять
     блок в общем контексте.

  ВАЖНО про блок 03: в файле части/03.html есть панель просмотра
     (кнопки резерва 0 / 5 / 10 / 15 %). Она вне меток БЛОК-НАЧАЛО и
     в отчёт не идёт, но команда «вынести» пересоздаёт файл из каркаса
     и панель стирает. После выноса вставить её заново, иначе вариант
     с программой лояльности будет не посмотреть.

  4. python3 блок.py вернуть 03
     Когда блок утверждён: он вшивается обратно в каркас.
     Файл части/03.html ОСТАЁТСЯ на месте — из папки «части»
     ничего не удаляется автоматически. Он лежит как последняя
     рабочая версия блока; чистить только вручную.

Пункты 2-3 повторяются сколько угодно раз. Отчёт всё это время
рабочий и целый: сборка берёт из файла блока только кусок
между метками.
web/превью.py     показывает один блок отдельной страницей:
                  python3 превью.py card01
                  Кладёт результат в _превью_card01.html — это
                  временный файл, в проекте его хранить не нужно.

═══════════════════════════════════════════════════════════
ПРАВИЛО ВЕРСИЙ
═══════════════════════════════════════════════════════════

В папке web всегда лежит ТОЛЬКО актуальная версия.
Перед каждой правкой прошлая версия уезжает в
_архив/вёрстка/ с датой и номером.

Так в рабочей папке никогда не бывает двух похожих файлов
и не нужно гадать, какой из них свежий.

═══════════════════════════════════════════════════════════
ЧТО В АРХИВЕ
═══════════════════════════════════════════════════════════

_архив/вёрстка/       прошлые версии calc.html и report.html
_архив/книга/         точки отката книги: «Калькулятор_до_чего-то»
_архив/img_исходники/ картинки, из которых сделаны вшитые в HTML
                      изображения: icons-*, illu-*, n-*, apple-half,
                      логотип.png — гайдлайн утверждённого знака
                      (четыре ромба крестом)
_архив/скрипты/       две проверки, обе вызываются из собрать.py:
                        проверка_логотипа.py — 8 правил начертания знака
                        проверка_вёрстки.py  — скобки, переменные,
                        медиазапросы, дубли селекторов, сверка с прежней

Архив для работы не нужен. Он на случай, если понадобится
откатиться или посмотреть, как было раньше.

В рабочих HTML нет ни одной внешней ссылки на файл: все картинки
вшиты в base64. Папку img_исходники можно не носить с собой —
она нужна, только если картинку придётся перерисовать.

═══════════════════════════════════════════════════════════
ЧИСТКА АРХИВА — РУКАМИ, НЕ АВТОМАТОМ
═══════════════════════════════════════════════════════════

Каждая сборка кладёт копию в _архив/вёрстка/. За активный день
их набегает полсотни. Автоматически они НЕ удаляются — иначе
можно потерять нужное.

Правило: в конце дня или после утверждения финишной версии
чистим за собой сами. Разумно держать 10 последних отчётов
и 5 анкет — к более старым вернуться всё равно нереально,
блоки и палитра к тому времени уже другие.
