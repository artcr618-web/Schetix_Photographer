# Правило: три вида прайса — один слепок

Установлено владельцем 07.09.2026. Действует для `Веб/price.html`,
`PDF/Счётикс_прайс_демо.pdf` и печати/сохранения в PDF из прайса.

## 1. Три вида — одно содержимое

| Вид | Где | Что это |
|---|---|---|
| Просмотр | `price.html`, режим «Просмотр» (`#pc-print-view`) | **Эталон наполнения.** Всё, что между колонтитулами, сначала выравнивается здесь. |
| Контрольный PDF | `PDF/Счётикс_прайс_демо.pdf` | **Эталон колонтитулов и полей листа** (верх, низ, расстояние от верха до баннера). Наполнение — из просмотра, без изменений. |
| Печать / PDF пользователя | кнопка «Печатать», «Скачать прайс», `?print=1` | Контрольный PDF целиком: колонтитулы + наполнение просмотра. |

Правило одной строкой: **наполнение = просмотр, рамка листа = контрольный PDF,
печать = их сумма.** Ни один из трёх видов не правится по отдельности.

## 2. Порядок любой правки вёрстки прайса

1. Правка делается в общем сборщике слепка — файл `Веб/Окна/прайс_печать.js`
   (`собратьПечать` / `секцииТаблиц` / `таблицаНаСетке` / `клонПечБаннера` /
   `нижнийКолонтитул` / `установитьКолонтитулы`). Страница `price.html`
   только подключает его (`СЧХПечатьПрайса.создать(...)`). Отдельных
   «печатных» и «просмотровых» веток разметки не заводить.
2. Проверяется в трёх видах за один проход: открыть режим «Просмотр» →
   пересобрать контрольный PDF → распечатать (`?print=1&demo=1`).
3. Правка считается законченной, только если все три вида совпали.
   Расхождение любого из них — дефект, а не «следующая задача».

## 3. Данные

- Демо-режим (`?demo=1`) подставляет только числа расчёта. Никаких примерных
  текстов («Анна Лунёва», телефоны, адреса) — ни в один вид.
- Поле с временным значением (подсказка «Имя Фамилия», «Введите
  наименование», «0») **печатается** так же, как выглядит на экране — и на
  обложке, и во всех таблицах (решение владельца 07.09, заменяет прежнее
  правило «пустое не печатается»). Не печатаются только удалённые и скрытые
  блоки. Временный телефон/почта/сайт ссылкой не становятся.
- Все три вида берут одни и те же данные из одного места (состояние прайса и
  обложки в браузере). Отдельных «данных для PDF» нет.

## 4. Сетка таблиц

Все печатные таблицы прайса стоят на одной сетке — сетке «Коммерческой
фотосъёмки» (6 столбцов 24/16/14/17/13/16 %). Данные каждой формы занимают
столбцы по порядку слева направо, остальные пусты (`СЕТКА_ПЕЧАТИ`,
`таблицаНаСетке`).

## 5. Контрольный PDF

Контрольный PDF собирается только скриптом (не вручную из браузера), из того
же режима `?print=1&demo=1`, и пересобирается при каждой правке вёрстки прайса.
Ручные PDF в `PDF/` не кладутся.
