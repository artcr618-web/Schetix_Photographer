# Обновление точки и архива передачи

## Когда обновлять

- после каждого завершённого смыслового действия;
- после смены активной задачи;
- перед окончанием сессии;
- после исправления проверки;
- перед передачей ZIP новой сессии.

## Что обновлять в точке

`ТОЧКА_ПРОДОЛЖЕНИЯ.md` должна всегда содержать:

1. активную задачу и путь к ней;
2. место задачи в дорожной карте;
3. последнее полностью завершённое действие;
4. точные результаты проверок;
5. один открытый вопрос, если он есть;
6. точное следующее действие;
7. перечень решений, которые нельзя обсуждать повторно без противоречия.

Нельзя писать расплывчато: «продолжить работу», «разобраться с нулями»,
«починить отчёт». Нужно указывать поле, ветку, текущее и ожидаемое поведение.

## Как собирать архив

```bash
cd /home/user/Schetix_Photographer
python3 Инструменты/собрать_передачу_сессии.py
```

Скрипт:

- проверяет наличие обязательных файлов;
- создаёт `МАНИФЕСТ.json` с SHA-256;
- включает универсальные инструкции, точку, рабочие проводники, активные задачи,
  критический HTML, книгу и инструменты проверки;
- не включает `.git`, изображения, старую архивную книгу и прежние передачи;
- создаёт стабильный и датированный ZIP;
- проверяет созданный ZIP чтением всех записей.

## Что архив не делает

- не заменяет живую рабочую папку без сравнения;
- не решает конфликты автоматически;
- не восстанавливает пакеты среды;
- не даёт права пропустить обучение новой сессии;
- не превращает архивные документы в рабочий источник.

## Проверка свежести

В новой сессии сравнить:

- дату `ТОЧКА_ПРОДОЛЖЕНИЯ.md`;
- `created_at` в `МАНИФЕСТ.json`;
- SHA-256 критических файлов;
- статус активной задачи в живом `Задачи/РЕЕСТР.md`.

Если живая папка новее ZIP, использовать живую папку и пересобрать передачу.
Если ZIP новее, сначала показать различия владельцу; не перезаписывать молча.
