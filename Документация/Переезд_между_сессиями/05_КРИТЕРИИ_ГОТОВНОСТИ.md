# Критерии готовности новой сессии

Новая сессия допускается к правкам, только если выполнены все пункты.

- [ ] Назван правильный рабочий корень.
- [ ] Прочитаны шесть файлов комплекта передачи.
- [ ] Прочитаны README, регламент, дорожная карта, алгоритмы и реестр задач.
- [ ] Прочитан документ активной задачи полностью, включая последние записи.
- [ ] Проверен `calc()` и соответствующие участки report.
- [ ] Проверена структура основной книги.
- [ ] Объяснена иерархия источников правды.
- [ ] Названы запреты на самостоятельные продуктовые решения и разрушительные Git-команды.
- [ ] Названы последний завершённый шаг, открытый вопрос и следующий шаг.
- [ ] Выполнена интеграционная проверка; `упало = 0`.
- [ ] Выполнена сверка 15 сценариев Excel.
- [ ] Выполнена сверка глоссария.
- [ ] Проверены хеши файлов снимка по `МАНИФЕСТ.json` либо объяснены различия с более новой рабочей папкой.
- [ ] До завершения экзамена не было внесено ни одной правки.

## Формат отчёта готовности

```text
Рабочий корень:
Текущая архитектура:
Источники правды:
Активная задача:
Последнее завершённое действие:
Открытый вопрос:
Следующее действие:
Проверки:
Обнаруженные противоречия:
Файлы, которые затронет следующий шаг:
Почему можно продолжать без потери контекста:
```
