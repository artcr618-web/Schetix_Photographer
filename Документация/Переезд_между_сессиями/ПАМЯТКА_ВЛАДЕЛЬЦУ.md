# Памятка владельцу: переезд за 7 действий

1. Попросите старую сессию обновить `ТОЧКА_ПРОДОЛЖЕНИЯ.md`.
2. Попросите запустить все три проверки.
3. Попросите выполнить `python3 Инструменты/собрать_передачу_сессии.py`.
4. Сохраните `Счётикс_передача_АКТУАЛЬНАЯ.zip`.
5. Откройте новую сессию и приложите архив вместе с рабочей папкой проекта,
   если она не переносится автоматически.
6. Отправьте по одному промпты 1–5 из `02_ПРОМПТЫ_ДЛЯ_НОВОЙ_СЕССИИ.md`.
7. Если экзамен пройден, отправьте промпт 6.

Не пересказывайте проект своими словами. Если новая сессия просит повторить
закрытые решения, направьте её обратно к этапам 2–5 и потребуйте назвать
фактическое противоречие.
