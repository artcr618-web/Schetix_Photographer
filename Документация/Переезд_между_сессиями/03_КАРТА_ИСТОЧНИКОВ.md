# Карта источников для новой сессии

## Иерархия доверия

1. Фактический исполняемый код и действующая основная книга.
2. Канонические рабочие реестры, правила и активные задачи.
3. Точка продолжения и дорожная карта.
4. Архивные документы — только для причин и истории.
5. Текст разговора и память модели — не источник правды без проверки.

## Источники

| Что нужно узнать | Где проверять |
|---|---|
| Расчёт | `calc()` в `Веб/calc.html` |
| Excel-зеркало | лист `calc` основной книги |
| Понятия | лист `01_Глоссарий` |
| Пользовательский справочник | строки с Назначением `user` на листе `01_Глоссарий`; `карта.py` автоматически публикует их в report/PDF |
| Состав групп | лист `Состав` |
| Дефолты, min/max/step, состояния | `Значения_по_умолчанию` |
| Страницы, блоки, ветки, роли управления | `Интерфейс` |
| Контракт `d`, показатели и диаграммы | `Полный_отчёт` |
| Тексты | лист `Тексты` и действующий HTML |
| CSS | `CSS_и_компоненты` и действующий HTML |
| Правила | `Архитектура — Правила модели и интерфейса.md` |
| Паспорта | `Документация/Описания расчётов/` |
| Автоматическое формирование детализации и справочника PDF | `Документация/АРХИТЕКТУРА_ДАННЫХ_PDF.md` |
| Активная работа | `ТОЧКА_ПРОДОЛЖЕНИЯ.md`, затем документ задачи |
| Все задачи | `Задачи/РЕЕСТР.md` |
| Порядок крупных этапов | `Документация/ДОРОЖНАЯ_КАРТА.md` |

## Обязательная цепочка правки

```text
понятие → поле → calc() → d → report → книга → паспорт → RULE → тест
```

Не каждый шаг меняется в каждой задаче, но каждый обязан быть проверен.

## Команды доказательства

```bash
cd /home/user/Schetix_Photographer
python3 Инструменты/проверить.py /home/user/Schetix_Photographer
python3 Инструменты/сверить_глоссарий.py
python3 Инструменты/проверить_сценарии_чистой_книги.py
```

Норма: `0 упало`; 15 сценариев Excel без расхождений; глоссарий без
расхождений. Информационное замечание о понятиях без явных ссылок допустимо,
пока оно явно помечено как информационное.

## Что не читать как текущую истину

- `Документация/03_ПОЛНАЯ_МЕХАНИКА_И_АЛГОРИТМЫ_25авг_2026.md`;
- `Архив/Документация/ПЕРЕДАЧА_В_НОВУЮ_СЕССИЮ.md`;
- старую контрольную книгу;
- rollback-файлы и исходники прежней вёрстки.

Они полезны только после установления текущего состояния.
