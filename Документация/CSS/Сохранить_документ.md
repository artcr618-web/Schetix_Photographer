# Окна «Сохранить документ» и «Поделиться» — паспорт

> Паспорт окна и кнопок сохранения. Решение владельца 04.09.2026:
> одна иконка, одно окно, разное наполнение по документу.
> Соседние паспорта: `Меню.md` (кнопки меню, набор иконок),
> `Сердечки.md` (окно «Поблагодарить»).

---

## 1. Что это и зачем

Окно, которое открывается по кнопке «Сохранить отчёт» (отчёт) и
«Сохранить прайс» (прайс). Раньше отчёт печатал напрямую, а прайс держал
собственную копию окна `#saveModal`; теперь **окно одно** и живёт в
отдельном файле `Веб/Окна/сохранить.js`. Дизайн правится в одном месте —
меняется на всех страницах. Каждая страница передаёт только своё
наполнение: заголовок, описание, имя файла, как печатать и как собрать файл.

Разделение обязанностей (владелец, 04.09):

| Кнопка | Что уходит | Куда |
|---|---|---|
| **Поделиться** (три кружка) | **ссылка на сервис** «Счётикс» | VK · Telegram · MAX · копирование |
| **Сохранить документ** (стрелка в лоток) | **сам документ** — файл или бумага/PDF | загрузки · печать · мессенджер/почта |

## 2. Где живёт и как подключено

| Файл | Роль |
|---|---|
| `Веб/Окна/сохранить.js` | стили, разметка, поведение окна, плашка-уведомление (если на странице нет своей `СЧХТост`) |
| `Веб/report.html`, конец файла, `<script>` «ОКНО «СОХРАНИТЬ ОТЧЁТ»» | наполнение для отчёта (`window.СЧХДокумент`) + строка подключения |
| `Веб/price.html`, блок «Окно «Сохранить прайс» — общее окно» в основном скрипте | наполнение для прайса + строка подключения в конце файла |
| `Веб/Части/каркас.html` | зеркало отчёта (cp), как требует АЛГОРИТМЫ.md §5 |

Подключение — последней строкой страницы, после её собственных скриптов:

```html
<script src="Окна/сохранить.js"></script>
```

Путь относительный: файл лежит рядом со страницами, поэтому **при
публикации на хостинг папка `Веб/Окна/` выкладывается вместе с
`report.html` и `price.html`** (как `fonts/` и `img/`). Если файл не
подключился, кнопки работают по-старому: печать напрямую
(`PHR_PRINT('main')` в отчёте, `печатьПрайса()` в прайсе).

Окно вставляется в `body` **вне корня страницы** (`#phr-root`), как
плашки-уведомления, — поэтому его стили не зависят от корня и палитра
вшита числами (значения — из палитры отчёта).

## 3. Наполнение — что передаёт страница

```js
window.СЧХДокумент = {
  заголовок:   'Сохранить отчёт',            // «Сохранить прайс»
  описание:    '…',                          // строка под заголовком
  имяФайла:    function(){ return '…' },     // без расширения, .html добавит окно
  напечатать:  function(){ … },              // печать / сохранение в PDF
  собратьФайл: function(){ return html },    // самодостаточный HTML (строка или Promise)
  письмо:      { тема: '…', текст: '…' }     // черновик письма для «Написать письмо»
};
```

Любое поле может быть функцией — берётся её результат при открытии.
Нет `собратьФайл` — плитки «Скачать файл» и «Отправить» не показываются;
нет `напечатать` — не показывается плитка печати.

| Документ | Заголовок | Имя файла | Печать | Файл |
|---|---|---|---|---|
| отчёт | «Сохранить отчёт» | «Расчёт от ДД.ММ.ГГГГ · Юнит-экономика для фотографов · Счётикс» (как у PDF) | `PHR_PRINT('main')` | копия `#phr-root` со всеми стилями: без меню, плашки, окон, кнопок печати, пробного режима и словаря терминов (состав печати «основной отчёт»); детализация раскрыта; диаграммы показаны сразу; ссылки на анкету — полные адреса |
| прайс | «Сохранить прайс» | «Прайс — Имя» (без имени — «Прайс») | `печатьПрайса()` | печатный слепок `#pc-print-view` со стилями и колонтитулами, фото баннера вшито (прежний `собратьФайлHTML`) |

Открыть окно из кода: `СЧХСохранить()`. Служебное:
`СЧХСохранить.закрыть()`, `СЧХСохранить.действие('скачать'|'печать'|'отправить')`,
`СЧХСохранить.имяФайла()`, помощник `СЧХСохранить.слепок({узел, стили, титул, классТела})`.

## 4. Дизайн — канон

Геометрия и типографика **повторяют окно «Поделиться»** (`.shm`, эталон
`report.html`), чтобы два соседних окна выглядели одной семьёй.

| Параметр | Значение |
|---|---|
| подложка | `rgba(26,26,26,.55)`, размытие 6 px, `z-index 90` |
| окно | ширина 100 %, `max-width 500`, `min-width 296`, радиус 20, отступы 34/34/30, тень `0 18px 60px rgba(16,24,40,.28)`, текст по центру |
| крестик | 34×34, радиус 12, справа сверху (14/16), фон `rgba(16,24,40,.05)` |
| заголовок | 21 px / 600 / `-.02em`, цвет `#4B5563` (`--c-ink3`) |
| описание | 13.5 px / 1.6, `#6B7280` (`--c-gr`), `max-width 26em` |
| ряд плиток | `gap 16`, `margin-top 26` |
| плитка | 44×44, скруглённый квадрат (viewBox 48, `rx 14`), белый рисунок |
| подпись | всплывает под плиткой при наведении (та же плашка, что у кнопок меню: 12.5 px / 600, радиус 12, тень) |
| без наведения (`hover:none` — телефоны, планшеты) | подписи стоят под плитками постоянно: 12 px / 500, `#6B7280` |
| ≤ 600 px | `padding` окна 28/20/26, заголовок 19 px, `gap 12` |
| печать | `display:none` |
| закрытие | крестик, фон, Esc; фокус возвращается на кнопку, с которой открыли; прокрутка страницы на время окна останавливается (класс `ос-стоп` на `html`) |

Плитки (порядок слева направо):

| Плитка | Подпись | Цвет | Рисунок |
|---|---|---|---|
| скачать | «Скачать файл» | `#21A038` (`--c-g-500`) | та же «стрелка в лоток», что на кнопке меню (эталон `report.html`), белым |
| печать | «Напечатать или сохранить в PDF» | `#2F80C4` (`--c-b-600`) | принтер |
| отправить | «Отправить» | `#6D3FD4` (`--c-v-700`) | летящий конверт |

Классы: `.ос` (подложка), `.ос-окно`, `.ос-крестик`, `.ос-заголовок`,
`.ос-описание`, `.ос-ряд`, `.ос-знак[data-ос]`, `.ос-подпись`; id окна
`#окноСохранить`.

## 5. Поведение плиток

| Плитка | Что происходит |
|---|---|
| **Скачать файл** | собирается самодостаточный `.html` документа → уходит в загрузки браузера → окно закрывается → плашка «Файл сохранён в загрузки». Файл открывается в любом браузере; PDF из него делается печатью. |
| **Напечатать или сохранить в PDF** | окно закрывается → через 80 мс печать страницы (`напечатать`) — системный диалог, где выбирается принтер или «Сохранить как PDF». Имя PDF подставляется страницей (как и раньше). |
| **Отправить** | если у браузера есть системное окно «Поделиться» с файлами (телефоны, Windows 10+/Chrome, macOS/Safari) — открывается оно с файлом: мессенджеры, соцсети, почта. Отмена человеком — тихо, без сообщений. Если системного окна нет (настольные Firefox, старые браузеры) — файл уходит в загрузки, плашка «Файл сохранён в загрузки — приложите его к письму или сообщению» с кнопкой **«Написать письмо»** (открывает почтовую программу с темой и текстом из `письмо`; файл прикладывается вручную — браузер не умеет вкладывать файлы в `mailto:`). |

Так закрыта жалоба владельца «в прайсе печать работает, а отправка в
мессенджеры не работает»: раньше на настольном браузере плитка «Отправить
файл» молча скачивала `.html` и ничего не объясняла; теперь понятно, что
произошло и что делать дальше.

Уведомления — общая плашка `СЧХТост` (отчёт и анкета уже имеют свою; в
прайсе её раньше не было, `alert()` заменён копией той же плашки из общего
файла).

## 6а. Окно «Поделиться» — ссылка на сервис (шаг 4, 04.09)

Окно `#shModal` (`.shm`) осталось **на каждой странице своей копией**
(разметка между метками `<!--ПОДЕЛИТЬСЯ-НАЧАЛО-->…<!--ПОДЕЛИТЬСЯ-КОНЕЦ-->`),
но с 04.09 все три копии — отчёт, анкета, прайс — **побайтно одинаковы**
по разметке, CSS и логике; эталон — `report.html`.

| Что | Значение (одинаково на трёх страницах) |
|---|---|
| заголовок | «Поделиться «Счётикс»» (`.shm-марка` — название жирным) |
| слоган | «Создан специалистами для специалистов на основе реального опыта», `max-width 26em` |
| плитки | ВКонтакте · Telegram · MAX — PNG-знаки 44×44 (вшиты в код), подписи «Поделиться ВКонтакте / в Telegram / в MAX» |
| поле адреса | `schetiks.ru`, кнопка «Скопировать ссылку» |
| **ссылка** | всегда **`https://schetiks.ru`** — адрес сервиса (решение владельца 04.09), не адрес текущей страницы |
| текст к ссылке | «Счётикс — юнит-экономика для фотографа» |
| VK / Telegram | `vk.com/share.php?url=…&title=…` / `t.me/share/url?url=…&text=…` в новой вкладке |
| MAX | системное окно «Поделиться» (`navigator.share`); без него — ссылка в буфер + плашка «Ссылка скопирована — вставьте её в MAX» |
| уведомления | плашка `СЧХТост` (в прайсе её даёт `Окна/сохранить.js`), `alert` не используется |
| запасной путь без окна | системное окно или буфер — тоже со ссылкой на сервис |

Что было до 04.09: отчёт и анкета делились `location.href` (у отчёта —
длинная ссылка с данными расчёта), поле показывало `calc.schetix.ru`;
прайс — собственная версия окна: заголовок «Поделиться прайсом», SVG-плитки,
третья плитка «Ещё…», слоган 28em, `alert` вместо плашки, ссылка на адрес
прайса (без данных — получатель видел бы демо-прайс).

## 7. Как проверить руками

1. Открыть `report.html` → «Сохранить отчёт» в верхнем меню и в плавающей
   плашке → одно и то же окно с тремя плитками; Esc, крестик, фон закрывают.
2. «Скачать файл» → файл `Расчёт от … · Счётикс.html`; открыть его —
   отчёт без меню и кнопок, диаграммы нарисованы, детализация раскрыта.
3. «Напечатать…» → системный диалог печати с именем PDF как раньше.
4. «Отправить» на телефоне → системное «Поделиться» с файлом; на настольном
   Firefox → файл в загрузках + плашка с кнопкой «Написать письмо».
5. То же в `price.html` (три кнопки: две в меню и большая под таблицами);
   файл называется «Прайс — Имя.html».
6. «Поделиться» на любой из трёх страниц → одинаковое окно, в поле
   `schetiks.ru`; VK и Telegram открывают окно отправки с этой ссылкой;
   «Скопировать ссылку» → плашка «Ссылка скопирована», в буфере
   `https://schetiks.ru`.

## 9. Открытые вопросы

1. Файл документа — `.html`, не PDF (решение 04.09: PDF делается печатью).
   Если понадобится настоящий `.pdf` файлом, нужна генерация PDF в браузере —
   отдельная задача с рисками по вёрстке.
2. Плитка «Отправить» через `mailto:` не умеет вкладывать файл — это
   ограничение браузеров; вложение остаётся ручным.
3. В прайсе имя файла «Прайс — Имя» опирается на подпись в баннере; при
   заглушке «ИМЯ ФАМИЛИЯ» файл называется просто «Прайс».
