# Счётикс · меню — эталон оформления

Обновлено: 3 сентября 2026 года (четвёртый заход: жест вместо крестика).
Решения владельца: 26.08.2026 (мобильное меню — только значки), 03.09.2026
(эталон — `report.html`; вёрстка плавающего меню на всех страницах одна,
у каждой страницы свой набор значков; надпись «счётикс» в плавающем меню —
только на десктопе и горизонтальном планшете; **ширина плашки динамическая** —
столько, сколько занимают элементы, ничего не сжимается; **крестика нет** —
плашку убирают под край экрана свайпом вверх и возвращают свайпом вниз).

Документ описывает **два меню**, которые есть на каждой странице:

| Меню | Что это | Класс | Где в разметке |
|---|---|---|---|
| **Стандартное** (верхнее) | ряд значков и логотип под шапкой страницы; прокручивается вместе со страницей | `.tbar` | блоки `REPORT-B001`, `CALC-B001`, `PRICE-B001` «Верхняя панель» |
| **Плавающее** (плашка) | появляется после 500 px прокрутки, висит по центру сверху, повторяет действия верхнего меню | `.fbar` (в анкете `.trustbar`) | отчёт — внутри `REPORT-B001`; анкета — `CALC-B002` «Плавающая панель»; прайс — сразу после `PRICE-B001` |

Эталон обоих меню — `Веб/report.html`. `calc.html` и `price.html` — копии; любое
изменение сначала вносится в эталон, затем переносится в копии. Сердечко
(значок «Поблагодарить проект») описано отдельно — `Документация/CSS/Сердечки.md`;
здесь оно упоминается только как один из значков ряда.

## 1. Общие правила значков (для обоих меню)

Значок — квадратная кнопка с контурной иконкой внутри. Правила одни для
верхнего и плавающего меню и для всех страниц; отличается только **набор** значков.

| Параметр | Значение |
|---|---|
| элемент | `<button class="fbi" type="button">` или `<a class="fbi" href="…">`; в анкете в плавающем меню — `.trustbar-action` |
| размер кнопки | **34 × 34 px**, `flex:none` (не сжимается), `flex` по центру, `padding:0`, `border:0` |
| радиус | 12 px |
| фон в покое | прозрачный |
| цвет в покое | `var(--c-gr)` = `#6B7280` |
| наведение | фон `var(--c-white)` `#FFFFFF`, цвет `var(--c-ink2)` `#374151` |
| нажатие (`:active`) | `transform:translateY(1px)` |
| переходы | `background .18s, color .18s, transform .12s` |
| иконка | `<svg viewBox="0 0 24 24" fill="none">`, **20 × 20 px**, контур `stroke="currentColor"` толщиной 1.8–2 (у каждой иконки своя, см. §5), концы `round` |
| подпись | нет; смысл — в подсказке `data-tip` и в `aria-label` (одинаковый текст) |
| подсказка (`.fbi:after`) | текст из `data-tip`; белая плашка `var(--c-white)`, текст `var(--c-ink)`, рамка `1px solid var(--c-ln)`, радиус 12, поля **10 px 14 px**, кегль **12.5 px** / 600, `white-space:nowrap`, тень `0 8px 28px rgba(16,24,40,.16)`; стоит на `calc(100% + 9px)` под кнопкой по центру; появляется за `.16s` (прозрачность + сдвиг 4 px вверх) |
| крайние подсказки (только прайс) | классы `.tip-l` / `.tip-r` прижимают подсказку к левому/правому краю кнопки, чтобы длинный текст не уходил за экран. В отчёте и анкете подсказки короче — классы не нужны |
| состояние «переспросить» (только анкета) | `.ask` на кнопке сброса: цвет `var(--c-r-700)`, фон `var(--c-r-50)`; ставится скриптом на 5 с после первого нажатия |

Сердечко `.fbh` подчиняется этим же правилам (покой `--c-gr`, наведение белый /
`--c-ink2`); нажатое состояние `.thx-горит` — см. Сердечки.md §2.

### 2.4 Точки перелома (мобильное поведение)

| Ширина окна | Что меняется | Решение |
|---|---|---|
| **> 820 px** (десктоп, горизонтальный планшет) | полный вид: знак 46 + надпись «счётикс», поля 12/20, зазор 10, кнопки 34 | — |

### 2.4а Формула ширины

Плашка — `flex` без ограничений ширины; у знака и каждого значка
стоит `flex:none`, поэтому браузер никогда их не ужимает. Ширина складывается:

```
десктоп (>700):  20 + знак + 14 + N×(34+10) + 20        gap 10 стоит и после знака
                 знак = 46 (+7+«счётикс» при >820)
телефон (≤620):  12 + 38 + 8 + N×(34+8) + 12             gap 8 стоит и после знака
```

Замер в Chromium 03.09 после снятия крестика (совпадает с формулой):

| Страница | Значков N | > 820 | 701–820 | 621–700 | ≤ 620 |
|---|---|---|---|---|---|
| отчёт | 4 | 364 | 293 | 269 | 249 |
| анкета | 3 | 320 | 249 | 227 | 207 |
| прайс | 5 | 408 | 337 | 311 | 291 |

Каждый добавленный значок расширяет плашку на 44 px (десктоп) / 42 px
(телефон). Ни на одной ширине окна элементы не сжимаются. После снятия
крестика плашка прайса на телефоне (291 px) помещается уже на 320 px.

### 2.5 Поведение (скрипт)

- появляется, когда прокрутка > **500 px**; исчезает, когда меньше;
- крестика нет — убирается и возвращается жестом (§2.6);
- каждая кнопка плавающего меню дублирует одноимённую кнопку верхнего меню:
  обработчики вешаются парами (`dlBtn`/`dlBtn2`, `shareBtn`/`shareBtn2` …), в
  анкете `trustShareBtn` вызывает `shareBtn.click()`.

### 2.6 Жест «убрать под край экрана» (вместо крестика)

Решение владельца 03.09: крестик снят; плашку убирают **свайпом вверх** и
возвращают **свайпом вниз** (или тапом по оставшейся полоске).

| Параметр | Значение |
|---|---|
| состояние | класс `убрана` на плашке; живёт до перезагрузки страницы. Если плашка убрана, то при уходе наверх (< 500 px) она гаснет, а при новом появлении появляется **снова убранной**, а не развёрнутой |
| положение убранной | `transform:translateX(-50%) translateY(calc(var(--fb-peek) − var(--fb-top) − 100%))` — плашка целиком уходит за верхний край, снаружи остаётся полоска высотой `--fb-peek`: **12 px** на десктопе, **10 px** на ≤ 700 px (= нижнее поле плашки, так что значки скрыты полностью, а видна только «подложка») |
| ручка | `.убрана:after` — черта 36 × 4 px, радиус 2, цвет `var(--c-gr3)`, по центру, на 3 px выше нижнего края |
| зона захвата | `.убрана:before` — невидимая полоса 24 px под плашкой, чтобы за 10-пиксельный край было удобно взяться пальцем |
| анимация | та же, что у появления: `transform .28s ease`; во время ведения пальцем переход отключён — плашка идёт за пальцем |
| порог жеста | путь по вертикали **> 24 px** → жест; движение до 8 px вообще не считается (значок получает обычный клик); между 8 и 24 px — жест начат, но плашка возвращается на место, клик подавлен |
| направление | вверх из развёрнутого → убрать; вниз из убранного → вернуть; «не туда» — плашка просто возвращается в прежнее состояние |
| тап по полоске | убранная плашка возвращается по короткому касанию полоски (не по значку) |
| события | Pointer Events (`pointerdown/move/up/cancel` + `setPointerCapture`) — палец и мышь; `touch-action:none` на плашке, чтобы браузер не перехватил свайп под прокрутку |
| скрипт | функция `СЧХЖестПлашки(bar)` — одна и та же в трёх файлах, эталон в `report.html` («жест плавающей плашки»); в анкете вызывается для `#trustBar`, в отчёте и прайсе для `#fbar` |
| клавиатура / без указателя | жест недоступен; плашка тогда просто остаётся развёрнутой (как и раньше без нажатия на крестик) |

Проверено в Chromium 03.09 (эмуляция pointer-событий) на трёх страницах:
свайп вверх по значку убирает плашку и **не** вызывает действие значка; свайп
вниз возвращает; тап по полоске возвращает; движение 3 px по значку не мешает
клику; после ухода наверх и возврата плашка появляется убранной.
