## 2. Анкета: `calc()` — что читает и что отдаёт

| Что | Сколько | Примеры |
|---|---|---|
| Числовые поля формы `V('id')` | 26 уникальных | `post_ratio`, `client_time`, `shoot_manual`, `frames_out`, `home_rent`, `edu_life` |
| Галочки и переключатели `CHK()`/`rad()` | 8 | `own_home`, `acc_mode`, `ws_mode`, `fm_on` |
| Исключённые блоки `EXC['Form…']` | 7 | `FormPromoTime`, `Form011`, `Form009b`, `Form006`, `FormClientTime` |
| Таблицы-каталоги через `sumF()` | 7 (+ `t_Form006` напрямую) | `Form001` техника, `Form002` офис, `Form003` подписки, `Form004` ПО, `Form007` реклама, `Form010` банк, `Form013` рабочее место |
| Прямые обращения к DOM внутри `calc()` | 4 | `$('fm_on')`, `$('regime')`, `$('npd_who')`, `$('acq_name')` |
| Глобальные константы вне `calc()` | календарь `ND`, `NT`, `EFF`, `Q`, `MO`; `PROF` (профессия — строка «фотографа») |
| Результат `d` | 123 ключа | `R`, `C`, `NT`, `pool`, `sh`, `post`, `clT`, `K`, `cl`, `S`, `depShoot…depWs`, `taxAll`, `rateHour`, `Rb`, `rateZero`, `discP`, `regime`, `profession` |

Ключевое: **`calc()` = чтение формы + формулы в одном теле.** Каталоги
(`Form001` и др.) считаются функцией `sumF(f)` по правилу поля `k` каталога:
`life` → стоимость / срок службы (амортизация в год), `per` → стоимость × период,
`months` → 0 (учитывается иначе). Построчный состав каталогов в `d` **не попадает** —
только суммы (`depShoot` и т.п.).

Сохранение состояния анкеты — `phc_state` (значения всех полей + число строк
таблиц), результат — `phc_report`. Контракт `d` описан в
`Документация/АРХИТЕКТУРА_ДАННЫХ_PDF.md` и на листе `Полный_отчёт` книги.

## 6. Целевая архитектура

```
Веб/Ядро/расчёт.js          чистые функции, без DOM, без localStorage
  ├─ расчёт(вход) → d                   ядро (сегодняшний calc() без чтения формы)
  ├─ прайс.ступениОбъёма(d, шаг)        ступени, срочный проект, скидка
  ├─ прайс.ценаУслуги(d, часы, кол, режим, шаг)
  ├─ прайс.консультация(d, часы, шаг)
  ├─ отчёт.износКамеры(d), отчёт.лояльность(d), отчёт.разрезы(d)
  └─ КОНСТАНТЫ: ВЕДЕНИЕ_ЗАКАЗА, ВЕДЕНИЕ_КОНС, СРОЧН, календарь

Веб/Профессии/фотограф.js   данные: блоки-счётчики, значения по умолчанию,
                            тексты, глоссарий, какие разделы отчёта/прайса есть

Веб/calc.html   снимок формы → вход → расчёт(вход) → d → phc_report
Веб/report.html d → отчёт.* → вывод (формул нет)
Веб/price.html  d → прайс.* → вывод + ручные правки (формул нет)
```

Слой «вход ядра» — плоский объект: числовые поля по `id`, галочки, режимы,
исключённые блоки и **списки строк каталогов** (название, стоимость, срок/период).
Списки нужны, чтобы прайс в будущем мог предложить «аренду по анкете»
(сейчас в `d` только суммы).

Подключение — как у общего окна сохранения: `<script src="Ядро/расчёт.js">`
перед скриптами страницы; при отсутствии файла страница показывает понятную
ошибку (самодиагностика уже есть в `price.html`), а не молча демо.

## 7. Что даёт вынос и чего он стоит

**Даёт:**
1. Одна правда: правка формулы = один файл + книга (сейчас три файла + книга).
2. Прайс получает канон и проверки: 20/40 минут, срочность, ступени — в книге и в `проверить.py`.
3. Тестируемость без браузера: `расчёт(вход)` проверяется на любом входе за миллисекунды.
4. Профессии как конфигурация, без второго `calc()`.
5. Фундамент для связей прайса с анкетой («подставить из анкеты» для аренды).

**Стоит:**
1. Новый контракт «вход ядра» — описать в книге и документации.
2. Перенастройка инструментов (харнесс, проверить, сборщики книги).
3. Решения владельца по книге (Р1, Р2) — без них волны 2–3 не стартуют.
4. Риск регрессии — снимается золотым снимком и сценариями (см. `00_ЗАДАЧА.md` §6).
5. Деплой: ещё один обязательный файл рядом со страницами (как `Окна/сохранить.js`).

**Вывод (совет от 05.09):** вынос эффективнее текущего устройства **только при
целях (а) и (б)**; обе цели у владельца есть, поэтому — делать, тремя волнами,
после завершения задачи 4 по прайсу.

## 8. Как обновить числа этого паспорта

```
# границы calc() и число строк
a=$(grep -n "^function calc()" Веб/calc.html | cut -d: -f1); b=$(awk -v a=$a 'NR>a && /^}/ {print NR; exit}' Веб/calc.html); echo $a $b
# поля, галочки, исключения, каталоги внутри calc()
sed -n ${a},${b}p Веб/calc.html | grep -o "V('[a-z_0-9]*')" | sort -u | wc -l
sed -n ${a},${b}p Веб/calc.html | grep -o "CHK('[a-z_0-9]*')\|rad('[a-z_0-9]*')" | sort -u | wc -l
sed -n ${a},${b}p Веб/calc.html | grep -o "EXC\['[A-Za-z0-9]*'\]" | sort -u | wc -l
sed -n ${a},${b}p Веб/calc.html | grep -o "sumF('[A-Za-z0-9]*')" | sort -u
# обращения отчёта к d
grep -c "d\.[A-Za-z]*" Веб/report.html
# константы прайса
grep -n "var ВЕДЕНИЕ_ЗАКАЗА\|var ВЕДЕНИЕ_КОНС\|var СРОЧН\|var СТАВКА\|var ЧАС_СЪЁМКИ" Веб/price.html
# упоминания формул прайса в книге (ожидается 0 до выноса)
python3 - <<'EOF'
import openpyxl; wb=openpyxl.load_workbook('Книга/Калькулятор_ставки_часа.xlsx',read_only=True); n=0
for ws in wb.worksheets:
    for row in ws.iter_rows(values_only=True):
        for v in row:
            if isinstance(v,str) and any(k in v for k in ('40 мин','20 мин','Срочн','срочн')): n+=1
print(n)
EOF
```
