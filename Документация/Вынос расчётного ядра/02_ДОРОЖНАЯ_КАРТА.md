## Правила выполнения (действуют для всех волн)

1. По одному шагу, с подтверждением владельца; каждый шаг заканчивается
   коммитом и строкой в `Решения и правки` карточки `З-047`.
2. После каждого шага: `python3 Инструменты/проверить.py "$PWD"` (не меньше
   текущего числа проверок, 0 упало), золотой снимок, при правке отчёта —
   `каркас.html` = `report.html`.
3. Существующие листы книги не меняются без согласия владельца; сложность —
   сообщается, а не обходится.
4. Поведение для пользователя не меняется: цифры, тексты, вёрстка до и после
   одинаковы. Любое расхождение — стоп и разбор.
