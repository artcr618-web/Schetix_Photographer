# Правило: превью ломается из-за огромных строк base64

Обновлено: 25.09.2026, по факту поломки report.html

## Симптом
- При скачивании на компьютер `report.html` открывается нормально
- Внутри превью Arena (iframe sandbox="allow-scripts") — пусто, белый экран
- В логе вьювера: `[267 KB elided from the middle of the file]` — вьювер вырезает кусок файла посередине

## Причина
В `report.html` были встроены большие картинки как `data:image/...;base64,...` в одну строку:
- `img` инвестиций: 273 664 символа в одну строку (data:image/webp;base64, 267KB)
- персонажи: `управляющий` 155 479 символов, `маркетинг` 32KB и т.д.

Вьювер Arena имеет лимит на длину строки / размер встроенного ресурса. При превышении он делает elide — вырезает кусок посередине файла, ломая HTML-структуру (теряется закрывающий </div> или </script>). Поэтому превью пустое, а скачанный файл целый.

`calc.html` самая длинная строка — 16KB, поэтому превью работало.

## Фикс (простой, как просила)
Разбивать все base64 строки длиннее 10KB на чанки по 8KB с конкатенацией JS:

```js
// было (одна строка 155KB):
'управляющий':'iVBORw0KGgoAAAANSUhEUgAAAOQAAAIwCAYAAACWZ8ed...155KB...'

// стало (нет строки длиннее 8KB):
'управляющий':'iVBORw0K...8000'+
'...ещё8000...'+
'...остаток'
```

Для data URI в HTML (картинка инвестиций 273KB) — нельзя вставлять `'+` внутри атрибута `src=""`, это ломает картинку (как было 25.09 вечер: src содержал `"+`). Правильно: оставить `<img id="invScene">` без src, а src собрать JS-чанкami:

```js
var b64 = 'UklGRjQh...8000' +
          '...ещё8000...' +
          '...остаток';
document.getElementById('invScene').src='data:image/webp;base64,'+b64;
```

После такого разбиения самая длинная строка 8KB, elide не срабатывает, картинка работает и в превью, и локально.

После разбивки:
- самая длинная строка — 22KB (было 273KB)
- data URI — макс 8KB (было 267KB)
- размер файла тот же (1.5MB на диске, 1.28MB текста), но превью не делает elide

Альтернатива для будущего: вынести картинки в `img/Персонажи/` как внешние файлы — тогда HTML 800KB, превью работает без картинок (graceful degradation), а при скачивании папки целиком картинки грузятся.

## Проверка
- `python3 -c "max(len(l) for l in open('Веб/report.html').read().split('\n'))"` → должно быть < 25000
- превью открывается, 15 карточек, `PHR_D.Ny` есть
- скачанный файл открывается локально с картинками
