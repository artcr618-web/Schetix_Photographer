# Расчёт — Регулярные расходы специалиста

Обновлено: 28 сентября 2026 (по слову владельца: Состав vari = 6 позиций, банковские включают кредиты).

Эталон понятия: лист `01_Глоссарий`, **№ 123 «Регулярные расходы специалиста»** (ранее №124, нумерация сдвинута после добавления №151).

> Расходы, возникающие регулярно и необходимые для поддержания профессиональной деятельности и выполнения работы в течение определённого периода.

---

## 1. Назначение

Показатель объединяет повторяющиеся денежные расходы специалиста за расчётный год.

В `calc()` имеет ID `vari`.

Регулярные расходы специалиста входят в Финансовые расходы:

```javascript
C = amort + vari;
```

---

## 2. Состав понятия

Эталон состава — лист `Состав`, строка с ID `vari` (обновлено 28.09):

1. Подписки;
2. Реклама;
3. Банковское обслуживание (включая платежи по кредитам);
4. Бухгалтерия;
5. Содержание рабочего места;
6. Наёмные сотрудники.

На листе `Состав` хранится только эта понятийная группировка. Формула находится на листе `calc` и в `Веб/calc.html`. Блоки анкеты лежат в секции Расходы, кредиты — в блоке 16 (банк), сотрудники — в блоке 18, поэтому оба входят в регулярные.

---

## 3. Фактический алгоритм `calc()`

```javascript
vari =
  sumF('Form003') +   // Подписки, блок 12
  sumF('Form010') +   // Реклама, блок 15
  sumF('Form007') +   // Банковское обслуживание, блок 16
  sumF('Form012') +   // Платежи по кредиту, блок 16, внутри банковских
  sumF('Form024') +   // Наёмные сотрудники, блок 18
  accM +              // Бухгалтерия, блок 17
  wsY;                // Содержание рабочего места, блок 13
```

Каждая часть приводится к годовому значению.

Для периодической строки каталога:

```text
Расход за год = Стоимость одного платежа × Количество платежей в год
```

Количество платежей:

- год — 1;
- квартал — 4;
- месяц — 12.

## 4. Подписки

Источник: `Form003`.

В демо-наборе:

| Позиция | Платёж | Период | ₽/год |
|---|---:|---:|---:|
| Adobe CC Photography | 2 000 ₽ | месяц | 24 000 ₽ |
| Яндекс Диск 1 ТБ | 3 000 ₽ | год | 3 000 ₽ |
| **Итого Подписки** | | | **27 000 ₽** |

Пользователь может добавлять, изменять и удалять строки.

Если исключён общий блок программного обеспечения, `Form003` получает эффективный ноль. Сырые значения сохраняются.

## 5. Реклама

Источник: `Form010`.

В демо-набор входят:

- домен сайта;
- хостинг сайта;
- Яндекс Директ;
- Авито;
- таргетированная реклама;
- размещения у блогеров;
- отклики на Profi.ru.

Годовой итог по умолчанию:

```text
187 500 ₽/год
```

Каждая строка считается по указанной стоимости и периоду. Пользователь может изменить состав каталога.

---

## 6. Банковское обслуживание

Источник: `Form007` + `Form012` (блок 16, секция Расходы — кредиты лежат в банковских расходах).

В демо-наборе:

| Позиция | ₽/год |
|---|---:|
| Обслуживание счёта (РКО) | 1 200 ₽ |
| СМС-уведомления | 600 ₽ |
| Платежи по кредиту | 0 ₽ (пустая строка по умолчанию) |
| **Итого** | **1 800 ₽** |

В эту группу входят регулярные банковские платежи и платежи по кредитам.

Не входят:

- Эквайринг;
- дополнительные процентные банковские комиссии.

Они зависят от Выручки и учитываются отдельно.

При исключении банковского блока:

- `Form007 = 0`, `Form012 = 0`;
- Эквайринг и дополнительные процентные комиссии также получают эффективный ноль.

## 7. Бухгалтерия

Расчёт зависит от выбранной ветки `acc_mode`.

### Специалист ведёт учёт самостоятельно

```text
accM = 0 ₽
```

Вместо денежного расхода учитывается время на Учёт в составе Временных расходов.

### Учёт ведёт нанятый специалист

```javascript
accM = acc_cost_month * 12;
```

По умолчанию выбрана самостоятельная ветка, поэтому:

```text
Бухгалтерия = 0 ₽/год
```

При исключении блока обе ветки получают эффективный ноль.

---

## 8. Содержание рабочего места

ID `wsY`. Имеет две взаимоисключающие ветки.

### Работа дома

```javascript
wsShare = cab_area / home_area;
wsY = (home_rent + home_util) * wsShare * 12;
```

По умолчанию:

```text
Стоимость жилья                   40 000 ₽/мес
Коммунальные платежи               7 000 ₽/мес
Общая площадь                         50 м²
Рабочая зона                           6 м²
Доля рабочей зоны                       12%
──────────────────────────────────────────
Содержание рабочего места         67 680 ₽/год
```

Галочка собственного жилья является контекстной и сама по себе не обнуляет расходы рабочего места.

### Отдельное помещение

```javascript
wsY = (office_rent + office_util) * 12;
```

Аренда и коммунальные расходы учитываются целиком.

### Исключённый блок

При исключении рабочего места:

```text
wsY = 0
```

Обустройство рабочего места также обнуляется, но относится уже к Финансовым вложениям.

## 8.1 Наёмные сотрудники

Источник: `Form024`, блок 18, секция Расходы.

По умолчанию одна пустая строка с 0 ₽, чекбокс «Не учитывать в расчёте» включён → эффективный 0.

При включении: `varEmp = сумма(ставка_мес * 12)`. Годовой пример: помощник 30 000 ×12 = 360 000 ₽/год.

Исключённый блок: `Form024 = 0`.

Глоссарий №151: физические лица по трудовому договору за регулярную зарплату.

## 9. Контрольный расчёт по умолчанию

| Составная часть | ₽/год |
|---|---:|
| Подписки | 27 000 ₽ |
| Реклама | 187 500 ₽ |
| Банковское обслуживание (включая кредиты) | 1 800 ₽ |
| Бухгалтерия | 0 ₽ |
| Содержание рабочего места | 67 680 ₽ |
| Наёмные сотрудники | 0 ₽ (выключены по умолчанию) |
| **Регулярные расходы специалиста** | **283 980 ₽** |

Проверка:

```text
27 000 + 187 500 + 1 800 + 0 + 67 680 + 0
= 283 980 ₽/год
```

С сотрудником 30 000×12:

```text
283 980 + 360 000 = 643 980 ₽/год
```

За месяц:

```text
283 980 ÷ 12 = 23 665 ₽/мес
```

## 10. Что не входит в показатель

В Регулярные расходы специалиста не входят:

- Съёмочное оборудование;
- Офисное оборудование;
- ПО, приобретённое разово;
- Обустройство рабочего места;
- Обучение;
- создание Сайта;
- Налоги;
- Эквайринг;
- дополнительные процентные банковские комиссии;
- Резервный фонд;
- Желаемый доход;
- Временные расходы.

Разовые денежные вложения относятся к Финансовым вложениям (инвестициям).

---

## 11. Эффективные нули

1. Выключенный блок остаётся в структуре, но его вклад равен нулю.
2. Удалённая строка каталога больше не участвует в сумме.
3. Пустая строка даёт нулевой вклад.
4. Неактивная ветка radio не участвует.
5. Самостоятельная Бухгалтерия даёт нулевой денежный вклад и ненулевой временной вклад.
6. Исключённый банк обнуляет регулярные и процентные банковские расходы.
7. Исключённое рабочее место обнуляет `wsY`.

## 14. Связанные показатели

- Финансовые расходы = Финансовые вложения + Регулярные расходы специалиста.
- Всего расходов = Финансовые расходы + Налоги + Эквайринг.
- Выручка покрывает Регулярные расходы через Финансовые расходы.
- Точка безубыточности учитывает Регулярные расходы как необходимую часть затрат.

---

## 15. Округление

Внутри `calc()` хранится точное значение. Пользователю деньги показываются до целого рубля. Округлённое отображение не возвращается в расчёт.
