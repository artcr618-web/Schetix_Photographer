# Расчёт — Финансовые расходы

Обновлено: 28 сентября 2026 (по слову владельца: блоки структурированы, кредиты в банковских, сотрудники в регулярных, обучение/сайт только в ВЛОЖ).

Эталон понятия: лист `01_Глоссарий`, **№ 131 «Финансовые расходы»**.

> Денежные средства, которые специалист затрачивает на выполнение работы и обеспечение профессиональной деятельности.

---

## 1. Назначение

Финансовые расходы показывают годовую сумму денежных затрат профессиональной деятельности до налогов, эквайринга, резервов и Желаемого дохода.

В `calc()` показатель имеет ID `C`.

---

## 2. Состав понятия

Эталон состава — лист `Состав`, строка с ID `C`:

1. Финансовые вложения (инвестиции);
2. Регулярные расходы специалиста (включая наёмных сотрудников и платежи по кредитам внутри банковских).

В `calc()`:

```javascript
C = amort + vari;
```

---

## 3. Финансовые вложения

```javascript
var equip = sumF('Form001') + sumF('Form001b') + sumF('Form002') + sumF('Form004');
var amort = equip + sumF('Form013') + sumF('Form013b'); // без eduY и siteY
```

Состав (обновлено 28.09, обучение и сайт только в ВЛОЖ через маржу, по слову 15.09):

1. Съёмочное оборудование — `Form001`;
2. Офисное оборудование — `Form002`;
3. ПО, приобретённое разово — `Form004`;
4. Обустройство рабочего места — `Form013`;
5. Обучение — `eduY`;
6. Сайт, заказанный у специалистов — `siteY`.

### 3.1. Распределение по сроку

Разовая стоимость не включается целиком в один год. Для строк типа `life`:

```text
Годовая часть вложения = Стоимость ÷ Срок использования
```

Поэтому `amort` — не первоначальная сумма всех покупок, а часть Финансовых вложений, относимая на один расчётный год.

### 3.2. Обучение

```javascript
eduOpp = eduMon * income_month;
eduY = (eduSum + eduOpp) / edu_life; // только для ВЛОЖ, не входит в amort с 15.09
```

Обучение учитывается только в инвестициях (ВЛОЖ) и возвращается через маржинальную прибыль. В ежемесячные финансовые расходы не входит (слово 15.09).

### 3.3. Сайт

```javascript
siteY = site_cost / site_life; // только для ВЛОЖ, не входит в amort с 15.09
```

Сайт, заказанный у специалистов, учитывается только в ВЛОЖ. В ежемесячные финансовые расходы не входит.

## 4. Регулярные расходы специалиста

```javascript
var vari =
  sumF('Form003') +   // Подписки, блок 12
  sumF('Form010') +   // Реклама, блок 15
  sumF('Form007') +   // Банк РКО, блок 16
  sumF('Form012') +   // Платежи по кредиту, блок 16, внутри банковских
  sumF('Form024') +   // Наёмные сотрудники, блок 18
  accM +              // Бухгалтерия, блок 17
  wsY;                // Содержание рабочего места, блок 13
```

Состав (обновлено 28.09, 6 позиций):

1. Подписки — `Form003`;
2. Реклама — `Form010`;
3. Банковское обслуживание — `Form007` + `Form012` (кредиты лежат в банковских расходах, блок 16);
4. Бухгалтерия — `accM`;
5. Содержание рабочего места — `wsY`;
6. Наёмные сотрудники — `Form024`, блок 18.

Для периодической строки годовой расход считается так:

```text
Стоимость одного платежа × количество платежей в год
```

Периоды:

- год — 1 платёж;
- квартал — 4 платежа;
- месяц — 12 платежей.

### 4.1. Содержание рабочего места

Работа дома:

```javascript
wsY = (home_rent + home_util) * (cab_area / home_area) * 12;
```

Отдельное помещение:

```javascript
wsY = (office_rent + office_util) * 12;
```

По умолчанию используется домашняя ветка:

```text
(40 000 + 7 000) × (6 ÷ 50) × 12 = 67 680 ₽/год
```

### 4.2. Бухгалтерия

Если учёт ведётся самостоятельно:

- денежный расход `accM = 0`;
- затрачиваемые часы учитываются во Временных расходах.

Если учёт ведёт специалист:

```javascript
accM = acc_cost_month * 12;
```

## 6. Что не входит в Финансовые расходы

В `C` не входят:

- Налоги;
- страховые взносы как часть налогового расчёта;
- Эквайринг;
- дополнительные процентные банковские комиссии;
- Резерв на отпуск;
- Маржинальной прибылинальная прибыль;
- Резерв на программу лояльности;
- Желаемый доход;
- компенсация Инвестиционного времени самостоятельно созданного сайта.

Эти величины учитываются на других этапах расчёта Выручки и Точки безубыточности.

## 7. Выключатели и ветки

### 7.1. Общий принцип

Выключенный блок сохраняет введённые пользователем значения, но его эффективный денежный вклад становится равен нулю.

### 7.2. ПО

Если исключён блок программного обеспечения:

```text
Form003 = 0
Form004 = 0
```

То есть одновременно обнуляются регулярные подписки и разовые лицензии.

### 7.3. Рабочее место

Если блок исключён:

```text
wsY = 0
Form013 = 0
```

Обнуляются и содержание, и обустройство рабочего места.

### 7.4. Обучение

Если блок исключён:

```text
eduY = 0
```

Не учитываются ни цена курса, ни упущенный доход.

### 7.5. Сайт

Если блок исключён:

```text
siteY = 0
sdiv = 0
```

Если выбран самостоятельный сайт, `siteY` равен нулю, но действует отдельная компенсация Инвестиционного времени.

### 7.6. Банк

При исключении банковского блока:

- `Form007 = 0`;
- эквайринг и дополнительные процентные комиссии получают эффективный ноль.

Внутри `C` находится только регулярное банковское обслуживание. Процентные комиссии в `C` не входят.

### 7.7. Бухгалтерия

Переключатель выбирает одну ветку:

- самостоятельный учёт — время;
- нанятый специалист — деньги.

Одновременно обе ветки не учитываются.

---

## 8. Нулевые и ошибочные случаи

1. Пустая необязательная строка каталога даёт нулевой вклад.
2. Нулевой или отсутствующий срок у разового вложения даёт нулевую годовую часть; автоматическая подмена срока не выполняется.
3. Если общая площадь жилья равна нулю, доля рабочего места принимается равной нулю, чтобы избежать деления на ноль.
4. Исключённый блок даёт эффективный ноль независимо от сохранённых сырых значений.
5. Финансовые расходы могут быть равны нулю, если все необязательные денежные блоки выключены или очищены; это допустимый расчётный результат.

Отрицательный пользовательский ввод должен отклоняться валидацией полей; полная валидация остаётся отдельной задачей З-035.

## 10. Родственные понятия

- **Финансовые вложения (инвестиции)** — первая группа внутри Финансовых расходов.
- **Регулярные расходы специалиста** — вторая группа.
- **Всего расходов** — Финансовые расходы вместе с Налогами и Эквайрингом.
- **Резервный фонд** — отдельная группа, не входящая в Финансовые расходы.
- **Временные расходы** — время, а не денежная часть `C`.
- **Инвестиционное время** — учитывается отдельно от годового рабочего времени; самостоятельный сайт компенсируется вне `C`.

---

## 11. Округление

Внутри `calc()` Финансовые расходы хранятся с полной точностью. Пользователю денежные значения показываются до целого рубля. Округление отображения не возвращается в формулы.

---

## 12. Проверки

Штатный сторож проверяет:

- совпадение значений по умолчанию книги и `calc()`;
- эффективные нули выключенных блоков;
- ветки рабочего места, сайта, банка и бухгалтерии;
- сходимость Выручки и Точки безубыточности при изменении расходов;
- наличие результатов у формул книги;
- синхронность DEMO и настоящего `calc()`.
