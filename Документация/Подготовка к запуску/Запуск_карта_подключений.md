# ПЕРВЫЙ ЗАПУСК · карта подключений

Главный файл папки. Здесь перечислено **всё, что нужно подключить**, чтобы
Счётикс заработал в интернете. Каждый пункт — отдельный шаг; по мере
проработки на каждый заводим свой файл с пошаговой инструкцией.

Правило: **не подключаем ничего, пока не дошли до пункта по порядку.**
Порядок выбран так, чтобы каждый следующий шаг опирался на готовый предыдущий.

Условные обозначения статуса:
`— не начато` · `~ в работе` · `+ готово` · `× решили не делать`

## Порядок работы

1. Берём пункт по порядку.
2. Проговариваем: зачем нужен, какие варианты, что выбираем.
3. Я пишу файл инструкции — по шагам, со скриншотами словами, с ценами.
4. Вы делаете, я проверяю результат.
5. Ставим `+` в таблице и переходим к следующему.

## Минимальный набор для запуска

Если совсем сжать, то в интернет можно выйти, закрыв только это:

**А1 · А2 · А3 · А5 · В1 · Г1 · Г2 · Г3 · Е1 · Е3**

Десять пунктов. Всё остальное можно добавлять после, на живом сайте.
