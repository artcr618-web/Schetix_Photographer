## 1. Как устроено

**`01_Механика_расчёта.md`** — самый большой документ, 1200 строк. Полный разбор:
все 27 листов Excel-книги с формулами, математическая модель от календаря до ставки
часа, разбор `calc.html` и `report.html` по функциям, сборка отчёта, контракт данных
между анкетой и отчётом, все найденные дефекты с числами.

**`02_Структура_и_стиль.md`** — дизайн-система и вёрстка. Палитра по семействам,
типографская шкала, сетки, тени, слои, восемь адаптивных порогов, печать. Дальше —
разбор каждого блока анкеты (30 штук) и отчёта (24 элемента) с классами и поведением,
все взаимодействия и десять правил, по которым проект сделан.

## 2. Как править

**`01_Атлас_связей.md`** — рабочий справочник. Матрица «меняю X → трогаю Y →
проверяю Z» для типовых правок, карта «поле анкеты → переменная → блок отчёта»,
семь мест, где легко сломать, и регламент безопасной правки. **Начинать отсюда.**

**`02_Публикация_на_Tilda.md`** — ограничения Tilda, схема с поддоменом, название
шрифта для подключения (Prata), что настроить в файлах перед публикацией.

## 4. Инструменты

| Файл | Что делает | Как запустить |
|---|---|---|
| `проверить.py` | **Главный.** 61 проверка: тождества расчёта, иерархия времени, кольцо диаграммы, программа лояльности, краевые случаи, логотип по 8 правилам книги, баланс тегов и CSS, сверка с книгой | `python3 проверить.py` |
| `харнесс.js` | Выполняет настоящие `calc()` и `parts()` из HTML без браузера — можно прогнать любой сценарий | `node харнесс.js /home/user/schetix '{"поля":{"regime":"usn6"}}'` |
| `карта.py` | Перестраивает все индексы в `5_справочники/индексы/` | `python3 карта.py` |
| `оптимизация.py` | Чистит мёртвый CSS и лишние пересчёты, пишет результат в отдельный файл | `python3 оптимизация.py исходник.html результат.html` |
| `модель_на_python.py` | Независимая реализация расчёта — для сверки «код против арифметики» | `python3 -c "from модель_на_python import *; print(calc())"` |

Проверки работают и на оригинале, и на вычищенной версии:

```
python3 проверить.py                      # оригинал
```

Сейчас обе дают **45 прошло · 14 упало · 5 замечаний**. Четырнадцать падений —
это известные дефекты, они специально оставлены как ловушки: когда мы их починим,
проверка позеленеет и подтвердит, что починка настоящая.

## Главное, что нужно помнить при правках

1. **Источник правды — Excel-книга**, но она ни разу не пересчитывалась: у формул
   нет сохранённых значений, самопроверки листа 04 никогда не отображались.
2. **`data-t` в вёрстке ничего не подставляет** — это просто пометка. Текст правится
   и в книге, и в HTML отдельно.
3. **`report.html` собирается из каркаса.** Правите каркас, потом `python3 собрать.py`.
   Каркас сейчас отстаёт от отчёта на семь строк — в нём «счетикс» без ё.
4. **Налоги считаются в двух местах по-разному** — в анкете и в отчёте. Пока модели
   не объединены, правку нужно вносить в оба файла.
5. **После любой правки — `python3 проверить.py`.** Число «прошло» не должно упасть,
   число «упало» — вырасти.
