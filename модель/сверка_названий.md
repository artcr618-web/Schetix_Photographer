## 4. Лист 01_Глоссарий — 161 наименование, 110 без понятия

Большая часть — служебные параметры и константы (`days_year`, `rate_npd_avg`,
лимиты, ID полей). Им понятия не нужны. Но там же живут **названия старой модели**,
которые противоречат справочнику и до сих пор используются в формулах книги:

| В глоссарии | В справочнике |
|---|---|
| ЧИСТОЕ время | **Эффективное рабочее время** |
| ОПЕРАЦИОННОЕ время | нет соответствия — понятия такого не завели |
| ПРОФИЛЬНОЕ время | нет соответствия |
| СЪЁМОЧНОЕ время (S) | **Съёмочный час** / **Съёмка** |
| Время на заказы до резерва | нет соответствия |
| ПРОЕКТНОЕ время | **Проектное время** ✓ |
| Резерв на форс-мажоры | **Резерв времени на форс-мажоры** |
| Учёт и планирование | **Учёт** |
| Всего расходов | **Прямые расходы** или **Текущие расходы** — смотря что имелось в виду |
| Переменные расходы | **Текущие расходы** |
| База для выручки | нет соответствия |
| Наивная ставка | нет соответствия |
| Базовая ставка | нет соответствия |
| Операционная ставка | нет соответствия |
| ПОЛНАЯ ставка / ПОЛНАЯ ставка рабочего часа | **Полная стоимость часа работы** |
| Час проектного времени / Стоимость часа проектного времени | **Стоимость клиентского часа** |
| Режим налогообложения | **Налоговый режим** |
| Создание сайта | **Сайт** |
