# З-055 · Кнопки «Поблагодарить проект»: надпись в одну строку

Файлы: Веб/report.html · .savebtn · .cta .btn2

## Зачем

На узких экранах надпись переносилась на две-три строки. Причина: фиксированный padding 0 30px и отсутствие white-space:nowrap. Замер до правки на 320px: .savebtn (две штуки) — 3 строки, .cta .btn2 — 2 строки.

## Что сделать

- [ ] Добавить white-space:nowrap обеим кнопкам
- [ ] Заменить фиксированный padding 0 30px на clamp(12px,4vw,30px)
- [ ] Проверено: 320/375/480/768 — все три кнопки в одну строку
