## Зачем

в подвале. Владелец: наверх вынести стоимость часа, доход опустить вниз
к выручке, заголовок оформить рамкой с чертой, единицы писать через слэш.

## Что сделать

- [x] заголовок в рамке с чертой под текстом
- [x] над кольцом — стоимость часа
- [x] под кольцом — доход на руки и выручка в месяц
- [x] обозначения через слэш: «стоимость / час», «на руки / мес»
