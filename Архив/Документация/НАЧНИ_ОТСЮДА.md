# НАЧНИ ОТСЮДА

Точка входа в проект «Счётикс». Прочитать этот файл — 5 минут,
после него понятно, что происходит и что делать дальше.

Обновлено 19 августа 2026.

---

## 1. Что это за проект

Калькулятор юнит-экономики для фотографов. Человек заполняет анкету
и получает отчёт: сколько должен стоить его час съёмки, чтобы после всех
расходов, налогов и эквайринга у него остался желаемый доход.

Три вещи, которые видит человек:

| Файл | Что это |
|---|---|
| `web/index.html` | обложка |
| `web/calc.html` | анкета и весь расчёт — функция `calc()` |
| `web/report.html` | отчёт: 21 блок, справочник на 77 записей, детализация из 8 таблиц |

Плюс книга `Калькулятор_ставки_часа.xlsx` — 29 листов: параметры, каталоги,
методика, тексты, стиль и, с этой сессии, глоссарий и отчёт внутри книги.

## 3. Где живёт правда

| Что | Источник | Что из него собирается |
|---|---|---|
| Понятия и параметры | лист `01_Глоссарий` книги | `модель/глоссарий.html` |
| Расчёт | `calc()` в `web/calc.html` | отчёт, демо-набор, документ группировок, лист `06b` |
| Определения для человека | словарь `СПРАВОЧНИК` в `web/части/таблицы_прототип.py` | справочник отчёта, подсказки анкеты, столбец сверки глоссария |
| Задачи | `ЗАДАЧИ/З-0NN_*.md` | `ЗАДАЧИ/РЕЕСТР.md` |

Источников пока два — глоссарий и справочник. Это временно и осознанно:
когда сверка закончится, справочник начнёт брать определения из листа
`01_Глоссарий`, и источник станет один. Этап описан в `ДОРОЖНАЯ_КАРТЕ`.

**Никогда не хранить те же данные третьим местом.** В этой сессии такое
случилось (снимок `глоссарий_данные.json`) и было немедленно убрано.

## 4. Где мы остановились — дословно

**Последнее, чем занимались: приведение глоссария в порядок.**

Лист `01_Глоссарий` стал единым реестром: 21 раздел, 260 строк, 12 столбцов
одинакового вида для всех разделов. Скрипт `модель/глоссарий.py` читает его
**по заголовкам столбцов** (порядок можно менять) и строит
`модель/глоссарий.html` — тот же реестр для чтения глазами. В книгу пишет
только по команде `--в-таблицу`.

Состояние сверки на момент остановки:

```
108  тождественно     название книги = запись справочника
 65  переименовать    соответствие проставлено в столбце сверки
  3  нет понятия      «Живу в своём», «Всего расходов», «ВСЕГО РАСХОДОВ (C)»
 84  не сверяется     внутренние величины расчёта

116  определений согласовано (формулировки пользователя)
138  черновик         мои формулировки, ждут её слов
```

**Последнее сделанное действие:** зафиксированы определения из справочника
по всем тождественным строкам (113 штук), внесено «Значение по умолчанию»,
у семейства «Чистого времени» проставлено определение «Эффективного рабочего
времени». Наименования не трогали — так велено.

**Что прямо сейчас лежит недоделанным:**
1. Три строки «нет понятия» — не разобраны.
2. 65 строк «переименовать» — соответствия проставлены, но сами наименования
   в книге не переименованы (пользователь: «наименование пока не трогаем»).
3. Временные столбцы (Статус, Справочник для сверки, Решение) стоят на месте —
   удаляем, когда сверка закончится.
4. Восемь вопросов пользователю заданы, ответов нет. Список и мои
   рекомендации — в `ПЕРЕДАЧА_В_НОВУЮ_СЕССИЮ.md`, разделы 2 и 2а.

**Ближайший шаг по плану:** досверить справочник (пункты 1–3 выше),
затем убрать временные столбцы и связать справочник с листом глоссария.

## 7. Правила, которые нарушать нельзя

1. Ничего не переименовывать и не менять по своей инициативе. Предложить → ждать «да».
2. Названия — только из справочника. Нет понятия — сначала завести запись.
3. Глоссарий и лист книги — одно и то же, правка идёт в оба.
4. Текстовых пояснений на страницы не добавлять — только справочник и подсказки.
5. Замечания по дизайну — в З-029, не править по ходу.
6. После каждой правки — `проверить.py`, «упало» = 0.
7. Пишем «Счётикс» — с прописной и через «ё».

Полностью — в `ДОРОЖНАЯ_КАРТА.md`, раздел «Правила работы».
