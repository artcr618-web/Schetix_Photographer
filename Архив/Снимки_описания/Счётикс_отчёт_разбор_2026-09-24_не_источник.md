## 2. Кольцо «Ваш доход за месяц» (REPORT-B030 / card01m)

### Инвариант

```
итог кольца = Ny / 12 = 110 216 ₽/мес  — в обоих мирах
```

Проверка харнессом:

- живой: эфф=1533 ч, k=1,142857, итог=110 216
- база: эфф=1533 ч, k=1,142857, итог=110 216

Формула `k = 1 + (idle+fmT)/эфф` (24.09: управление — свой сектор, в `k` больше не входит). Поэтому выключение управления лишь перераспределяет доли, но не меняет сумму.

Доли при каноне (управление выключено):

- фотограф 54,86 % (60 461 ₽/мес)
- маркетинг 28,57 % (31 490)
- продажи 13,71 % (15 115)
- бухгалтер 2,86 % (3 149)
- управленец **0 %** (0 ₽/мес)

Доли при DEMO (управление включено): 50,29 / 28,57 / 12,57 / 2,86 / 5,71.

### Дефект №1 — нулевая плашка остаётся

`НАПР` в `report.html:6058` строится из всех пяти ролей, включая управленца с `ч=0`. Далее:

```js
if(эфф<=0) return; // 0 не срабатывает, эфф=1533
// ...
НАПР.forEach — считает руб=hr*ч*k/МЕС → 0
// ...
точки[с.i] = ... // для нулевого сектора пропускается (t1-t0<1e-6 → return)
```

Результат живого рендера (jsdom, 24.09):

- `monC4` — `рост=1.250` | «Как управленец 0 ₽/мес 0.0% от общего дохода»
- кружок-магнит `#0F766E cx=0 cy=0` — не позиционирован
- выноска `#0F766E → 0.0,0.0 NaN,0.0 NaN,NaN NaN,NaN` — линия в никуда, `NaN` в координатах

Ожидаемое по правилу роста (`Документация/ПРАВИЛО_ДИАГРАММА_И_РОСТ_ПЕРСОНАЖЕЙ.md:83`):

> 0 % → 1,25 высоты плашки, чтобы персонаж с нулевой долей остался читаемой фигурой.

Правило предусматривает ноль, но **не предусматривает**, должна ли плашка вообще показываться. В коде `visIdx` фильтрует секторы по `mgmtT>0`, а `НАПР` — нет. Отсюда рассинхрон: сектор убран, плашка осталась.

В DEMO всё чисто: 5 кружков с координатами, 5 выносок без `NaN`.

### Дефект №2 — легенда календаря не знает управление

`Веб/report.html:8036-8044` — легенда:

```js
var СКР=[[WC.po,'Обработка',...],[WC.pr,'Продвижение',...],
         [WC.cl,'Работа с клиентом',...],[WC.ac,'Учёт',...],
         [WC.id,'Рабочие паузы',...]];
if(fmW>0.05) СКР.push([WC.fm,'Форс-мажоры',true]);
```

`mgW` (управление) нигде не добавляется. В итоге:

- при `mgmtT=0` — легенда корректна (управления нет)
- при `mgmtT=87,6` — в календаре ячейки управления есть (очередь `queue` включает `mgW`), а в легенде их нет — пользователь видит цвет `#0F766E` без подписи.

То же с таблицей «Время по периодам» (`8062`): массив `ВТ` — съёмка, обработка, продвижение, клиент, учёт, паузы; `fmT` добавляется условно, `mgmtT` — никогда.

### Что работает правильно

- `чПроч = (promo+accT+mgmtT+idle+fmT)/МЕС` — управление включено в третью плашку «Прочее» (58,40 ч/мес живой, 65,70 база) — инвариант `workHours=1752` (ш+пост+клТ+промо+аккТ+мгмтТ+айдл+фмТ) держится в обоих мирах.
- `HRS[16] = mgmtT/sh` — часы на час съёмки, 0 при выключенном.
- `incM = hr0*(sh+post+clT+promo+accT+mgmtT+idle)` — доход идеального сценария включает управление, когда оно есть.
- `k` больше не включает управление — исправлено 24.09.
