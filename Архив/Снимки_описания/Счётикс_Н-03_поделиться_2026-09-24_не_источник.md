## 1. Факт, снятый 24.09

### `calc.html` — делится сервисом

```js
// Делимся ссылкой на САМ СЕРВИС, а не на текущую страницу (решение владельца 04.09):
// у отчёта адрес с данными, у прайса — адрес без данных, получатель ничего полезного по ним не увидит.
// Адрес сервиса один.
var СЕРВИС_URL='https://schetiks.ru', СЕРВИС_ТЕКСТ='Счётикс — юнит-экономика для фотографа';
function ссылка(){return СЕРВИС_URL}
```

`window.СЧХПоделиться` открывает `#shModal`, поле `#shmАдрес` показывает `schetiks.ru` без `https://`. Кнопки VK, Telegram, MAX — `https://vk.com/share.php?url=...`, `https://t.me/share/url?url=...`, для MAX — системное `navigator.share` (мессенджер не даёт сайтам отправлять готовое сообщение).

`data-tip` — «Поделиться», иконка — три точки с линиями (share).

### `price.html` — тоже сервисом

```js
var СЕРВИС_URL = 'https://schetiks.ru' ...
function ссылка(){ return СЕРВИС_URL; }
```

Тот же комментарий, та же логика. Прайс без данных (`price.html` без `?data=` — данные подтягиваются из `localStorage` или из `report.html` через `?data=`), поэтому делиться прайсом с данными бессмысленно — получатель увидит пустой прайс. Делимся сервисом.

### `report.html` — делится открытой страницей

```js
/* ОКНО «ПОДЕЛИТЬСЯ» — ВКонтакте и Телеграм принимают ссылку прямо в адресе.
   У MAX такого адреса нет — ... */
function ссылка(){return location.href}
function заголовок(){return document.title||'Счётикс — расчёт стоимости часа';}
```

`location.href` — это адрес открытой страницы, включая `?data=...` (base64 отчёта) или чистый `report.html` с данными из `localStorage`. Получатель открывает тот же отчёт с теми же цифрами.

**Смысл разный — это задумано:**

- Анкета: ты ещё не посчитал, делишься сервисом.
- Прайс: ты редактируешь свой прайс, делиться им без данных бессмысленно — делишься сервисом.
- Отчёт: ты уже посчитал, хочешь показать расчёт — делишься отчётом с данными.

Паспорт `Документация/CSS/Меню.md` от 03.09 пишет: «все три делятся ссылкой на сервис» — это противоречит живому коду отчёта. Паспорт устарел.

### Домен

В коде везде `https://schetiks.ru` (с `k`), в паспорте встречается `schetix.ru` (без `k`). Написание домена в Н-03 не входит (отложено).
