### Как отчёт разделяет

**JS:** `report.html:5246 суммаБуфера`, `5252 суммаЧистойПрибыли`, `5262 parts()`

```js
function суммаБуфера(д){
  var явная=Number(д&&д.cushionY);
  if(isFinite(явная))return Math.max(0,явная);
  var общий=Number(д&&д.fundY)||0;
  var прибыль=Number(д&&д.profitY);
  if(isFinite(прибыль))return Math.max(0,общий-прибыль);
  // запасной путь: через fundP и R
  return Math.max(0,общий - (д.R*д.fundP||0));
}
function суммаЧистойПрибыли(д){
  var явная=Number(д&&д.profitY);
  if(isFinite(явная))return Math.max(0,явная);
  return Math.max(0,(д.fundY||0)-суммаБуфера(д));
}
```

`parts()`:
- `parts[11] = суммаЧистойПрибыли(x)` — чистая прибыль
- `parts[17] = суммаБуфера(x)` — буфер

`visIdx()`:
- `v.push(11); v.push(12); v.push(13); v.push(17);` — прибыль и буфер всегда показываются как резервы, даже если 0 (нулевая строка ведёт в анкету).

**Вывод:** отчёт **умеет отделить** буфер от чистой прибыли, даже когда анкета отдаёт только `fundY` и `fundP`. При `fund_on` и `cushion_on` включенных показывает 498 302 ₽ прибыли и 276 834 ₽ буфера как две отдельные строки в кольце резервов (B026 и B029).
