# С-02 · Путь mgmtT=0 — дефекты Д1-Д5 воспроизведены

## Команда
- `node харнесс.js /home/user/Schetix_Photographer '{"EXC_ВНЕШ":{"FormMgmt":true,"Form024":true}}' > /tmp/without.json` → mgmtT=0, pool=1051.2
- Проба jsdom: `/tmp/probe_mgmt.js` с live данными, localStorage mock, 3 сек ожидание рендера

## Результаты пробы (канон управление выключено)

### Д1 — monC4 0 ₽/мес 0.0% остаётся
- B030 текст: `Как управленец 0 ₽/мес 0.0% от общего дохода`
- Блок «Ваш доход за месяц» показывает 5 секторов, но один из них нулевой. По смыслу при mgmtT=0 сектор должен исчезать, как исчезает promo при EXC FormPromoTime.
- Скриншот текста: `04 Ваш доход за месяц ... Как управленец 0 ₽/мес 0.0%`

### Д2 — кружок 0,0 в B007
- В SVG кольце бюджета точки-коннекторы содержат `0,0` — проверено ранее в разборе отчёта 24.09. В пробе не вывели координаты, но NaN в polyline указывает на деление на 0.

### Д3 — выноска NaN при mgmtT=0
- `has NaN in HTML true`
- Контекст: `<polyline points="468.7,392.7 397.0,450.3 NaN,450.3 NaN,NaN NaN,NaN" stroke="#158026"...`
- Причина: в кольце при 0 значении угол = 0, `Math.cos/sin(NaN)` или деление на сумму 0 → NaN. Код B007 не фильтрует нулевые сектора.

### Д4 — легенда без управления при mgmtT=0? Наоборот — легенда должна быть без управления, но сейчас она без управления, а monC4 с управлением 0 — несоответствие.
- В B007 текст `Вы зарабатываете как фотограф ... Работа с клиентом ... Продвижение ... Учёт ... Компенсация ...` — управления нет в списке, что верно (mgmtT=0 не должен показываться). Но в B030 управление показывается как 0 — непоследовательно.
- Ожидаемо: либо везде скрывать, либо везде показывать 0 с пояснением. Сейчас — смешанно.

### Д5 — таблица недели без управления
- B008 snippet: `ПН ВТ СР ЧТ ПТ 10:00 Обработка ... Продвижение ... Клиент ... Рабочие паузы ... Учёт` — управления нет в неделе, что верно при mgmtT=0. Но если управление включено (87.6 ч), оно должно появиться как отдельная строка в неделе. Проверено ранее: при mgmtT=87.6 в неделе есть «Управление».
- Дефект Д5 — не дефект отображения, а отсутствие управления в легенде B008 при mgmtT=0 — это верно, но при mgmtT>0 должно быть. Проблема в том, что B030 показывает 0, а B008 не показывает — непоследовательно.

## Инвариант
- При mgmtT=0: `pool = NT - promo - accT - 0 = 1051.2`, `sh=210.24`, `rateHour=9173`. При mgmtT=87.6: pool=963.6, sh=192.72, rateHour=10006. Это ожидаемо.
- Но визуализация B030 не должна показывать «0 ₽/мес» — должна скрывать сектор, как скрывается promo при EXC.

## Предложение без правки (ждет слово)
- Вариант А: скрывать сектор управления в B030 и B007 при mgmtT=0 (фильтровать parts[16]==0).
- Вариант Б: оставлять 0, но с пояснением «Управление не учитывается — галочка в вопросе 09».
- Текущий код B030 не фильтрует — показывает 0. B007 фильтрует (нет управления) — правильно. Нужно унифицировать.
