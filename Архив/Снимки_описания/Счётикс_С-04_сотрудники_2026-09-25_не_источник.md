# С-04 · Наёмные сотрудники (Form024) — деньги в C, строки нет

## Команда
- Без сотрудников (канон Form024 checked): `харнесс.js ... '{"EXC_ВНЕШ":{"FormMgmt":true,"Form024":true}}' > /tmp/without.json` → C=457454, vari=283980, R=1928544
- С сотрудником 30 000 ₽/мес: `харнесс.js ... '{"CAT":{"Form024":{"k":"per","rows":[["Помощник фотографа",30000,12]]}},"EXC_ВНЕШ":{"FormMgmt":true}}' > /tmp/with_emp.json` → C=817454 (+360 000), vari=643980 (+360 000), R=2318576 (+390 032)

## Что в calc
- Form024 k='per', sumF = price*term = 30000*12=360000 в год
- vari = sumF Form003+010+007+012+024+accM+wsY → Form024 входит в vari
- C = amort+vari → входит в C
- ВЛОЖ не включает Form024 (только техника, софт, обучение, сайт) — верно, сотрудники не инвестиция

## Что в report
- `grep -n Form024 Веб/report.html` → 0 вхождений
- `grep -n varAcc|varRent|varBank|varSoft|varAds|depShoot` → все есть, Form024 нет
- B007 бюджет: parts = [sh, post, clT, promo, accT, idle, dep..., varAds+depSite, varRent+varBank+varAcc+varSoft, taxAll, aq, profit, discY, vac, depEdu, fmT, mgmtT, buffer]
- varRent+varBank+varAcc+varSoft = 67680+1800+0+27000=96480 — в живом дефолте. При сотрудниках vari растёт, но разбивка B007 не имеет отдельного varEmp — деньги падают в общий vari и в totalExpenses, но пользователь не видит строку «Сотрудники».
- Сумма строк разбивки: depShoot+depOffice+depSoft+depWs + varAds+depSite + varRent+varBank+varAcc+varSoft + taxAll + aq + profit + discY + vac + depEdu + fmT + mgmtT + buffer = C + taxAll + aq + profit + discY + vac? Проверка: при mgmtT=0, fmT=0, profit=0, buffer=0, discY=0 → сумма = amort+vari + taxAll+aq+vac = totalExpenses+vac? Должна сходиться, но если Form024 входит в vari, а vari входит в сумму как часть varRent+... — да, входит через vari? Нет, varRent+varBank+varAcc+varSoft не включает Form024. Form024 входит в vari, но не в var* — значит сумма строк ≠ C. Проверим:
  - Без сотрудников: dep 173474 + varAds+depSite 187500 + varRent+... 96480 + tax 96427 + aq 52070 + vac 110216 = 716167, а totalExpenses 605952 — расхождение из-за vac? Нужно пересчитать parts.

## Проверка суммы строк vs C
- Харнесс выводит __parts — это parts(x) без времени? В /tmp/without.json __parts = [145485,436455,145485,303094,30309,151547,173474,187500,96480,96427,52070,0,0,110216,0,0,0,0] — 18 элементов.
- parts[6]=173474 (dep), [7]=187500 (ads), [8]=96480 (rent+bank+acc+soft), [9]=96427 tax, [10]=52070 aq, [13]=110216 vac, остальные 0. Сумма 6..10,13 = 173474+187500+96480+96427+52070+110216=716167. totalExpenses=605952. Разница 110215 ≈ vacY. Значит totalExpenses = sum(6..10) = 605951, а vac отдельно.
- При сотрудниках 360k: __parts с сотрудником? В /tmp/with_emp.json нет __parts? Есть, но мы не вывели. Проверим: в with_emp __parts[8] должен вырасти на 360k? Но varRent+... не включает Form024, значит __parts не вырастет, а totalExpenses вырастет — сумма строк не сойдётся с totalExpenses на 360k. Это и есть Н-07.

## Вывод С-04
- Form024 входит в vari и C, но не входит ни в одно поле разбивки, которое читает отчёт (depShoot, depOffice, depSoft, depWs, varAds, varSoft, varBank, varRent, varAcc). Следовательно, сумма строк детализации не сходится с C на величину сотрудников.
- В отчёте 0 упоминаний Form024 — пользователь не видит, куда ушли 360k.

## Предложение (ждет слово «делаем Н-07»)
